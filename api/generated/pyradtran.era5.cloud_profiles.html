pyradtran.era5.cloud_profiles#

cloud_profiles(profile, reff_water_um=10.0, reff_ice_um=20.0, threshold_g_m3=0.0001)[source]#

Build wc_file / ic_file profile dicts from an ERA5 column.

Converts clwc / ciwc (kg/kg) to g m⁻³ using the ideal-gas air density, places layer boundaries midway between model levels, and writes the values with libRadtran’s 1D cloud-file semantics: the value at altitude z fills the layer above z, and the top row closes the grid with zero content.

Parameters:

  • profile (xarray.Dataset) – Single column, canonical names (see normalize_era5(), select_profile()), pressure_level in hPa. Needs t (K) plus at least one of clwc / ciwc (kg kg-1). z (geopotential) is used for the altitudes when present.

  • reff_water_um (float, default 10.0) – Effective radius (µm) assigned to every liquid row; ERA5 carries no particle size.

  • reff_ice_um (float, default 20.0) – Effective radius (µm) assigned to every ice row.

  • threshold_g_m3 (float, default 1e-4) – Levels at or below this water content (g m-3) count as cloud-free.

Returns:

  • wc (dict or None) – {"z": [...], "lwc": [...], "reff": [...]}: altitude (km), liquid water content (g m-3) and effective radius (µm) as plain lists, ordered top-down. None when clwc is absent or no level exceeds the threshold.

  • ic (dict or None) – Same with key "iwc" for ice, from ciwc.

Raises:

InputGenerationError – If profile has no pressure_level or no t.

See also

pyradtran.interface.PyRadtranAccessor.run

era5_clouds= calls this function per point; a dict passes keyword overrides, e.g. era5_clouds={"reff_ice_um": 35.0}.

Notes

Water content. ERA5 gives the cloud water as a mass mixing ratio \(q_c\) (kg of condensate per kg of air). With the dry-air ideal-gas density at pressure \(p\) (hPa) and temperature \(T\) (K)

\[\rho_\mathrm{air} = \frac{100\,p}{R_d\,T}, \qquad R_d = 287.058\ \mathrm{J\,kg^{-1}\,K^{-1}},\]

the volumetric water content in g m-3 is

\[\mathrm{LWC} = 1000\; q_c\; \rho_\mathrm{air}\]

(and likewise IWC from ciwc). No virtual-temperature correction is applied, and the grid-box mean is used as is (not divided by the cloud fraction cc). Negative values are clipped to zero.

Altitude. When profile has z it is converted according to its units attribute: a geopotential \(\Phi\) (m2 s-2, m**2 s**-2, …) gives the geopotential height

\[z = \frac{\Phi}{g_0}, \qquad g_0 = 9.80665\ \mathrm{m\,s^{-2}},\]

while m / gpm / km are taken as heights. Without a recognised unit, values above 105 are assumed to be a geopotential, anything else metres. Without z a constant 7 km scale height is used, \(z = -7\,\mathrm{km}\,\ln(p / 1013.25\, \mathrm{hPa})\), which is only a rough estimate. Altitudes are above mean sea level in both cases, not above the local surface.

Layers. Levels with NaN pressure, temperature, altitude or water content are discarded and the rest sorted by altitude, \(z_0 < z_1 < \dots < z_{n-1}\). Each level \(i\) represents the layer between the midpoints to its neighbours,

\[b_{i-1/2} = \tfrac12 (z_{i-1} + z_i), \qquad b_{i+1/2} = \tfrac12 (z_i + z_{i+1}),\]

with the outermost layers extended by half the adjacent spacing (the lowest boundary is not allowed below 0 km; a single-level profile gets ±0.05 km). If \(i_\mathrm{lo}\) and \(i_\mathrm{hi}\) are the lowest and highest level above the threshold, the returned rows are, from the top down,

\[(b_{i_\mathrm{hi}+1/2},\ 0), \quad (b_{i_\mathrm{hi}-1/2},\ c_{i_\mathrm{hi}}), \quad \dots, \quad (b_{i_\mathrm{lo}-1/2},\ c_{i_\mathrm{lo}})\]

so that every content value \(c_i\) sits at the lower boundary of its layer and the zero on top closes the grid, which is how libRadtran reads a wc_file 1D / ic_file 1D. One contiguous block is written per phase: levels between two cloud decks keep their own (sub-threshold) content instead of being set to zero.

Examples

A five-level column with liquid water at 850 and 925 hPa and a little ice at 500 hPa:

>>> import numpy as np
>>> import xarray as xr
>>> from pyradtran.era5 import cloud_profiles
>>> lev = "pressure_level"
>>> profile = xr.Dataset(
...     {
...         "t": (lev, [252.0, 268.0, 276.0, 280.0, 284.0]),
...         "z": (
...             lev,
...             [54000.0, 29500.0, 14500.0, 7500.0, 1000.0],
...             {"units": "m2 s-2"},
...         ),
...         "clwc": (lev, [0.0, 0.0, 2.0e-4, 3.0e-4, 0.0]),
...         "ciwc": (lev, [2.0e-5, 0.0, 0.0, 0.0, 0.0]),
...     },
...     coords={lev: [500.0, 700.0, 850.0, 925.0, 1000.0]},
... )
>>> wc, ic = cloud_profiles(profile)
>>> np.round(wc["z"], 3).tolist()
[2.243, 1.122, 0.433]
>>> np.round(wc["lwc"], 3).tolist()
[0.0, 0.215, 0.345]
>>> wc["reff"]
[10.0, 10.0, 10.0]

Read from the bottom: 0.345 g m-3 between 0.433 and 1.122 km (the 925 hPa level at 0.765 km), 0.215 g m-3 up to 2.243 km (the 850 hPa level at 1.479 km), nothing above. The ice cloud is a single layer around the 500 hPa level:

>>> np.round(ic["z"], 3).tolist(), np.round(ic["iwc"], 4).tolist()
([6.756, 4.257], [0.0, 0.0138])

Raising the threshold removes the thin ice cloud, and other effective radii can be assigned:

>>> wc, ic = cloud_profiles(profile, reff_water_um=8.0, threshold_g_m3=0.05)
>>> ic is None, wc["reff"]
(True, [8.0, 8.0, 8.0])

The dicts are valid wc_file / ic_file parameter values:

>>> result = ds.pyradtran.run(  
...     config_path=cfg, params={"wc_file": wc}
... )

A deeper synthetic column. Markers are the ERA5 level values, steps the layers libRadtran sees:

from pyradtran.era5 import cloud_profiles

p = np.array([300, 400, 500, 600, 700, 775, 850, 900, 950, 1000.0])
z_km = -7.6 * np.log(p / 1013.25)
t = 288.0 - 6.5 * z_km
clwc = np.array([0, 0, 0, 0, 0.3, 1.6, 2.6, 1.2, 0, 0]) * 1e-4
ciwc = np.array([0.15, 0.5, 0.35, 0.1, 0, 0, 0, 0, 0, 0]) * 1e-4
lev = "pressure_level"
profile = xr.Dataset(
    {
        "t": (lev, t),
        "z": (lev, z_km * 9806.65, {"units": "m2 s-2"}),
        "clwc": (lev, clwc),
        "ciwc": (lev, ciwc),
    },
    coords={lev: p},
)
wc, ic = cloud_profiles(profile)
rho = 100.0 * p / (287.058 * t)

fig, ax = plt.subplots(figsize=(5.5, 4.2))
for prof, key, mmr, color, label in (
    (wc, "lwc", clwc, "C0", "liquid (wc_file)"),
    (ic, "iwc", ciwc, "C1", "ice (ic_file)"),
):
    edges = prof["z"][::-1]
    values = prof[key][:0:-1]
    ax.stairs(values, edges, orientation="horizontal", color=color,
              fill=True, alpha=0.3)
    ax.stairs(values, edges, orientation="horizontal", color=color,
              label=label)
    ax.plot(1000.0 * mmr * rho, z_km, "o", color=color, ms=4)
ax.set_xlabel("water content (g m$^{-3}$)")
ax.set_ylabel("altitude (km)")
ax.set_ylim(0, 11)
ax.legend()
plt.tight_layout()
