pyradtran.config.load_config#

load_config(config_path=None)[source]#

Load and merge the three-layer configuration.

Three YAML sources are merged key by key, later layers winning:

  1. Package defaults: pyradtran/defaults.yaml. Provides a value for every setting, but only placeholder libRadtran paths.

  2. User master config: ~/.pyradtran/config.yaml, for machine-specific paths (see save_master_config()).

  3. Simulation config: config_path, describing one experiment.

Converting the merged mapping to dataclasses validates it (see PathsConfig and SimulationDefaults).

Parameters:

config_path (str or pathlib.Path, optional) – Simulation YAML file; it needs only the keys that differ from layers 1 and 2. None uses layers 1 and 2 alone.

Returns:

SimulationConfig – The merged, validated configuration. A new object on every call.

Raises:

  • ConfigurationError – If config_path cannot be read or is not valid YAML; if the merged paths.libradtran_bin, paths.libradtran_data or solar spectrum file do not exist (typically no master config has been written yet and the package placeholders are in effect; the message says how to set the paths); or if a merged value fails the SimulationDefaults validation. The exception is also a FileNotFoundError and a ValueError.

  • TypeError – If a required section is missing from all layers.

See also

save_master_config

Write layer 2.

SimulationConfig.to_yaml

Write a file usable as layer 3.

SimulationConfig.from_yaml

Load one file without any merging.

pyradtran.interface.PyRadtranAccessor.run

Calls this function when given config_path=; its params= argument is the per-run override on top of all three layers.

Notes

Precedence. Mappings merge recursively; every other value is replaced as a whole. A simulation YAML containing only

simulation_defaults:
  source: thermal
  wavelength_nm: [8000, 13000]

changes these two settings and inherits everything else from the master config and the package defaults. A list (wavelength_nm, output_columns, …) is replaced, never concatenated.

Short names. paths.atmosphere_profile and paths.solar_spectrum accept short names (afglsw, kurudz_1.0nm; see list_atmosphere_profiles() and list_solar_spectra()). They are resolved against the merged paths.libradtran_data, so a short name works with whatever installation the master config points to. The returned object holds full paths.

Missing files. A missing master config is skipped silently, and one that cannot be read or parsed is skipped with a logged warning. An unreadable package default file is logged as an error and treated as empty. Only an unreadable or unparsable config_path raises.

Unknown keys in any layer are ignored with a logged warning naming the key, so a typo such as albedo instead of albedo_value does not raise. Check the log (or the returned object) when a setting seems to have no effect.

Side effects. paths.output_dir and paths.working_dir are created if missing (relative paths: relative to the current working directory). execution.debug_mode: true sets the "pyradtran" logger to DEBUG.

Package vs dataclass defaults. The package defaults differ from the bare defaults of SimulationDefaults and ExecutionConfig in albedo_value: 0.85, surface_temperature_k: 273.15 and max_workers: 4.

Examples

Package defaults plus master config. Here the master config supplies the libRadtran paths and the short names afglus / NewGuey2003:

>>> from pyradtran import load_config
>>> cfg = load_config()  
>>> cfg.paths.libradtran_bin  
PosixPath('/opt/libRadtran-2.0.6/bin/uvspec')
>>> cfg.paths.atmosphere_profile  
PosixPath('/opt/libRadtran-2.0.6/data/atmmod/afglus.dat')
>>> cfg.paths.solar_spectrum  
PosixPath('/opt/libRadtran-2.0.6/data/solar_flux/NewGuey2003.dat')
>>> sd = cfg.simulation_defaults  
>>> sd.rte_solver, sd.wavelength_nm, sd.albedo_value  
('twostr', [400, 3600], 0.85)
>>> sd.output_columns  
['sza', 'eglo', 'eup', 'albedo']

A simulation YAML as the third layer. thermal.yaml:

paths:
  atmosphere_profile: afglsw
simulation_defaults:
  source: thermal
  wavelength_nm: [8000, 13000]

>>> cfg = load_config("thermal.yaml")  
>>> sd = cfg.simulation_defaults  
>>> sd.source, sd.wavelength_nm, sd.rte_solver  
('thermal', [8000, 13000], 'twostr')
>>> cfg.paths.atmosphere_profile  
PosixPath('/opt/libRadtran-2.0.6/data/atmmod/afglsw.dat')

Override settings for a single run. params accepts uvspec options (sza) and dotted config paths; cfg stays untouched:

>>> import pandas as pd
>>> import xarray as xr
>>> ds = xr.Dataset(
...     coords={
...         "time": pd.to_datetime(["2022-03-28 12:00"]),
...         "latitude": 78.9,
...         "longitude": 11.9,
...     }
... )
>>> cfg = load_config()  
>>> cfg.simulation_defaults.rte_solver = "disort"  
>>> cfg.simulation_defaults.integrate_wavelength = True  
>>> kwargs = dict(config=cfg, save_to_file=False, show_progress=False)  
>>> ref = ds.pyradtran.run(**kwargs)  
>>> float(ref.eglo.squeeze()), float(ref.eup.squeeze())  
(221116.9, 187949.4)
>>> low = ds.pyradtran.run(  
...     params={"simulation_defaults.albedo_value": 0.1, "sza": 60.0}, **kwargs
... )
>>> float(low.eglo.squeeze()), float(low.eup.squeeze())  
(518429.6, 51842.96)
>>> cfg.simulation_defaults.albedo_value  
0.85

A missing simulation file is an error:

>>> load_config("does_not_exist.yaml")
Traceback (most recent call last):
    ...
pyradtran.exceptions.ConfigurationError: Cannot read configuration file does_not_exist.yaml: [Errno 2] No such file or directory: 'does_not_exist.yaml'
