pyradtran.interface.execute_simulation_batch#

execute_simulation_batch(config, input_ds, params=None, time_var='time', lat_var='latitude', lon_var='longitude', albedo_var=None, surface_temperature_var=None, surface_type_var=None, altitude_var=None, era5_atmosphere=None, era5_clouds=False, parameter_overrides=None, progress_callback=None, cloud_wc_var=None, cloud_ic_var=None, cloud_reff_var=None, cloud_ic_reff_var=None, cloud_top_var=None, cloud_bottom_var=None, show_progress=True, return_outcomes=False, _example=None)[source]#

Run uvspec for every point in input_ds.

The input dataset is stacked over all its dimensions; each combination of coordinates is one simulation. Results come back in the same flat order, ready for convert_batch(). PyRadtranAccessor.run() builds on this and adds altitude handling, conversion to a dataset, the status variable, channel convolution, provenance and saving.

Parameters:

  • config (SimulationConfig) – Merged configuration, e.g. from load_config(). Dotted config keys in params modify it in place; pass config.copy() to reuse it.

  • input_ds (xarray.Dataset) – Input points. Every dimension is iterated; a dataset without dimensions (scalar time / latitude / longitude) is one point. A xarray.DataArray is converted with to_dataset().

  • params (dict, optional) – Parameter mapping, as in PyRadtranAccessor.run(). Preferred over the deprecated *_var and parameter_overrides arguments.

  • time_var (str) – Names of the time / latitude / longitude variables in input_ds (coordinates or data variables).

  • lat_var (str) – Names of the time / latitude / longitude variables in input_ds (coordinates or data variables).

  • lon_var (str) – Names of the time / latitude / longitude variables in input_ds (coordinates or data variables).

  • albedo_var (str, optional) – Deprecated; use params={"albedo": Var(...)}.

  • surface_temperature_var (str, optional) – Deprecated; use params={"sur_temperature": Var(...)}.

  • surface_type_var (str, optional) – Deprecated; use params={"brdf_rpv_type": Var(...)}.

  • altitude_var (str, optional) – Deprecated; use params={"zout": Var(...)}.

  • era5_atmosphere (xarray.Dataset, optional) – ERA5 dataset for the atmosphere files, in CDS or ARCO-ERA5 naming (normalised with pyradtran.era5.normalize_era5()). An ozone profile (o3) is written into the radiosonde file and the config ozone_du scaling is then skipped.

  • era5_clouds (bool or dict, default False) – Also derive per-point wc_file / ic_file cloud profiles from the ERA5 clwc / ciwc fields. A dict is passed as keyword arguments to pyradtran.era5.cloud_profiles() (e.g. {"reff_water_um": 8.0}). Explicit cloud parameters (params or cloud_*_var) take precedence. Requires era5_atmosphere.

  • parameter_overrides (dict, optional) – Deprecated; use params.

  • progress_callback (callable, optional) – callback(current, total) called after each simulation.

  • show_progress (bool, default True) – Show a tqdm progress bar.

  • return_outcomes (bool, default False) – Return PointOutcome objects (status and failure detail) instead of parsed outputs.

  • cloud_wc_var (str, optional) – Dataset variables holding the liquid / ice water content (g m-3) of a single homogeneous cloud layer per point.

  • cloud_ic_var (str, optional) – Dataset variables holding the liquid / ice water content (g m-3) of a single homogeneous cloud layer per point.

  • cloud_reff_var (str, optional) – Effective-radius variables (µm) for liquid and ice. Missing or NaN values fall back to 10 µm (liquid) and 20 µm (ice). Without cloud_ic_reff_var the ice phase uses cloud_reff_var.

  • cloud_ic_reff_var (str, optional) – Effective-radius variables (µm) for liquid and ice. Missing or NaN values fall back to 10 µm (liquid) and 20 µm (ice). Without cloud_ic_reff_var the ice phase uses cloud_reff_var.

  • cloud_top_var (str, optional) – Cloud-boundary variables (km). Required with cloud_wc_var or cloud_ic_var.

  • cloud_bottom_var (str, optional) – Cloud-boundary variables (km). Required with cloud_wc_var or cloud_ic_var.

Returns:

list of ParsedOutput or None – One entry per flattened input point, in stacking order (input_ds.stack(sample=list(input_ds.sizes))). None for failed or skipped points. With return_outcomes, a list of PointOutcome instead.

Raises:

  • ValueError – If time_var / lat_var / lon_var is not in input_ds, if cloud variables lack a boundary variable or are missing from the dataset, or if era5_clouds is given without era5_atmosphere.

  • ValidationError – If params contains an unknown option, an out-of-range literal, a Var pointing to a missing variable, or a per-point value that fails validation.

  • PyRadtranError – If all simulations fail.

What runs for each point.

Notes

Per-point handling. Points with missing/NaT time or NaN latitude/longitude are not run (status 2). A Var parameter whose dataset value is NaN is dropped for that point: the configuration default applies and the point still runs.

Parallelism. With execution.max_workers equal to 1, points run serially in the calling process. None (one worker per CPU) or a value > 1 uses a concurrent.futures.ProcessPoolExecutor. Each uvspec subprocess is limited by execution.timeout_seconds.

ERA5. One atmosphere file per unique (time, latitude, longitude) is written to <paths.working_dir>/era5_atmospheres/ and shared by all points with these values (e.g. along a sweep dimension). If writing fails, a warning is logged and the point runs with the configured standard atmosphere.

Failures. When a point fails or is skipped, a failures_<YYYYmmdd_HHMMSS>.log file in config.paths.working_dir lists point id, status and detail/stderr per point. The .inp file of a failed uvspec run is kept for post-mortem.

Examples

>>> import pandas as pd
>>> import xarray as xr
>>> from pyradtran import execute_simulation_batch, load_config
>>> ds = xr.Dataset(
...     coords={
...         "time": pd.date_range("2025-06-21T08:00", periods=3, freq="4h"),
...         "latitude": ("time", [61.0, 61.0, 61.0]),
...         "longitude": ("time", [22.0, 22.0, 22.0]),
...     }
... )
>>> config = load_config("config/quickstart.yaml")  
>>> outputs = execute_simulation_batch(  
...     config, ds, params={"wavelength": [500, 502]}, show_progress=False
... )
>>> len(outputs)  
3
>>> outputs[0].data["edir"]  
array([1046.489, 1029.557, 1019.107])

Status per point:

>>> outcomes = execute_simulation_batch(  
...     config, ds, params={"wavelength": [500, 502]},
...     show_progress=False, return_outcomes=True,
... )
>>> outcomes[0].status, outcomes[0].point_id  
(0, '20250621_080000_61.00_22.00_0')
