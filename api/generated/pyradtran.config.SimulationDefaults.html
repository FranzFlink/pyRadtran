pyradtran.config.SimulationDefaults#

class SimulationDefaults(rte_solver='twostr', mol_abs_param='lowtran per_nm', source='solar', wavelength_nm=<factory>, integrate_wavelength=False, output_columns=<factory>, output_altitudes_km=<factory>, albedo_value=None, surface_temperature_k=None, ozone_du=300.0, h2o_mm=2.0, h2o_source='fixed', clouds=<factory>, viewing_geometry='nadir', sza=None, parameter_overrides=<factory>)[source]#

Bases: object

Physics and spectral settings (YAML section simulation_defaults).

Each field maps onto one line of the uvspec input file that InputFileBuilder writes for every simulated point. The values are defaults: the params mapping of run() replaces the corresponding lines for one run.

Parameters:

  • rte_solver (str, default "twostr") – Radiative-transfer solver, written as rte_solver <value> ("twostr", "disort", "fdisort1", "rodents", …). twostr is fast but computes irradiances only and can become unstable for optically thick clouds; use disort for radiances and cloudy scenes.

  • mol_abs_param (str, default "lowtran per_nm") – Molecular absorption parameterisation, written as mol_abs_param <value> (e.g. "reptran coarse", "kato2"). An empty string omits the line.

  • source ({“solar”, “thermal”}, default "solar") – Radiation source. "solar" writes source solar <paths.solar_spectrum> plus sza and day_of_year (from the point’s time); "thermal" writes source thermal and, if set, sur_temperature.

  • wavelength_nm (list of float, default [400, 3600]) – Spectral range [min, max] in nm, written as wavelength <min> <max>. A mapping {"start": ..., "end": ...} is accepted and converted to the list form.

  • integrate_wavelength (bool, default False) – If true, output_process integrate is written and (solar source) per_nm is appended to the source line. Each output quantity is then one spectrally integrated number per altitude.

  • output_columns (list of str, default ["sza", "eglo", "eup", "albedo"]) – Quantities requested with output_user, in file order (e.g. edir, edn, eup, eglo, enet, uu). Each becomes a data variable of the result. lambda is added automatically for spectral runs and zout for runs with more than one output altitude; an empty list omits the line.

  • output_altitudes_km (list of float, default [0.0]) – Output levels in km, written as zout (sorted, duplicates removed). They become the altitude coordinate of the result.

  • albedo_value (float, optional) – Lambertian surface albedo (0–1), written as albedo <value>. With None the line is omitted and uvspec uses its own default (0). Not written when a run supplies albedo or brdf_rpv_type through params.

  • surface_temperature_k (float, optional) – Surface temperature in K, written as sur_temperature <value> for source="thermal" only. With None, uvspec takes the temperature of the lowest atmospheric level.

  • ozone_du (float, optional, default 300.0) – Total ozone column in Dobson units, written as mol_modify O3 <value> DU. None keeps the column of the atmosphere profile. Skipped when an ERA5 profile already provides ozone.

  • h2o_mm (float, optional, default 2.0) – Precipitable water in mm (kg m⁻²), written as mol_modify H2O <value> MM. None keeps the column of the atmosphere profile. Skipped when a radiosonde or ERA5 profile provides the humidity.

  • h2o_source ({“fixed”, “radiosonde”}, default "fixed") – "radiosonde" looks up the local sounding closest in time below paths.radiosonde_base (see RadiosondeFinder) and writes radiosonde <file> H2O RH. If no file is found the run falls back to the "fixed" behaviour (h2o_mm).

  • clouds (CloudParameters) – Static cloud settings; nothing is written unless clouds.enabled is true.

  • viewing_geometry (str, default "nadir") – "nadir" writes umu 1.0 (sensor looking straight down). Any other value writes no viewing-geometry line; set umu / phi through params or parameter_overrides instead.

  • sza (float, optional) – Fixed solar zenith angle in degrees (sza <value>, solar source only). With None it is computed for every point from its time and position by calculate_solar_zenith_angle().

  • parameter_overrides (dict, optional) – Any other libRadtran option, as {keyword: value} pairs applied to every run. A keyword that the typed fields above already wrote replaces that line; True writes a bare flag (aerosol_default), False removes the line, a list writes one line per entry.

Raises:

ConfigurationError – If wavelength_nm does not have exactly two elements (or, as a mapping, lacks start / end), source is not "solar" or "thermal", or albedo_value lies outside [0, 1]. The exception is also a ValueError.

Notes

validate() does the checks and the altitude sorting. It runs at construction (and so in load_config()). Later attribute assignments (sd.albedo_value = 2.0) are not checked until validate() is called again; run(), explain() and jacobian() of the accessor call it before simulating.

The total ozone column is given in Dobson units,

\[1\ \mathrm{DU} = 10^{-5}\ \mathrm{m\ (STP)} = 2.687 \times 10^{20}\ \mathrm{molecules\ m^{-2}},\]

and the water vapour column as precipitable water, the depth of the liquid layer the column would form:

\[\mathrm{PW} = \frac{1}{\rho_w} \int_0^\infty \rho_v(z)\,\mathrm{d}z, \qquad 1\ \mathrm{mm} \mathrel{\widehat{=}} 1\ \mathrm{kg\ m^{-2}} .\]

mol_modify rescales the profile of the background atmosphere so that its vertical integral matches the requested column; the profile shape is kept.

With integrate_wavelength the output is the band integral

\[E = \int_{\lambda_\mathrm{min}}^{\lambda_\mathrm{max}} E_\lambda(\lambda)\,\mathrm{d}\lambda\]

in the units of the solar spectrum file times nm (mW m⁻² for the Kurucz spectra, which are tabulated in mW m⁻² nm⁻¹).

Examples

Defaults:

>>> from pyradtran import SimulationDefaults
>>> sd = SimulationDefaults()
>>> sd.rte_solver, sd.mol_abs_param, sd.source
('twostr', 'lowtran per_nm', 'solar')
>>> sd.wavelength_nm, sd.output_columns
([400, 3600], ['sza', 'eglo', 'eup', 'albedo'])

Altitudes are sorted and de-duplicated; the mapping form of the wavelength range becomes a list:

>>> sd = SimulationDefaults(
...     source="thermal",
...     wavelength_nm={"start": 8000, "end": 13000},
...     output_altitudes_km=[10.0, 0.0, 10.0, 2.0],
... )
>>> sd.wavelength_nm, sd.output_altitudes_km
([8000, 13000], [0.0, 2.0, 10.0])

Invalid values are rejected:

>>> SimulationDefaults(albedo_value=1.5)
Traceback (most recent call last):
    ...
pyradtran.exceptions.ConfigurationError: albedo_value must be between 0 and 1, got 1.5

validate()[source]#

Check the settings and normalise them in place.

Runs at construction; call it again after assigning to attributes. It converts the mapping form of wavelength_nm to a list, checks wavelength_nm, source and albedo_value, and sorts and de-duplicates output_altitudes_km.

Raises:

ConfigurationError – See the class docstring. Also a ValueError.

Examples

>>> from pyradtran import SimulationDefaults
>>> sd = SimulationDefaults()
>>> sd.output_altitudes_km = [5, 0, 5]
>>> sd.validate()
>>> sd.output_altitudes_km
[0, 5]
>>> sd.albedo_value = 2.0
>>> sd.validate()
