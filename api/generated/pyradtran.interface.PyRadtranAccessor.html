pyradtran.interface.PyRadtranAccessor#

class PyRadtranAccessor(xarray_obj)[source]#

xarray accessor for running libRadtran simulations (ds.pyradtran).

Registered on every xarray.Dataset when pyradtran is imported. The dataset describes where and when to simulate, one uvspec run per point:

run([config_path, config, params, ...])

Run uvspec for every point in the dataset.

explain([point, params, config_path, ...])

Preview the annotated uvspec input file for one point.

jacobian(param, delta[, params, ...])

Finite-difference sensitivity kernel for one scalar parameter.

inspect_cloud_file([selector, params, ...])

Preview the cloud-profile file run() would write for a point.

  • run(): run uvspec for every point; results have the same dimensions.

  • explain(): annotated uvspec input file for one point, without running.

  • jacobian(): finite-difference sensitivity to one scalar parameter.

  • inspect_cloud_file(): preview the cloud-profile file built from the cloud_*_var arguments.

run_uvspec is a backwards-compatible alias of run().

Parameters:

xarray_obj (xarray.Dataset) – The dataset the accessor is attached to. Use ds.pyradtran; do not construct directly.

See also

execute_simulation_batch

The underlying batch driver.

pyradtran.params.Var

Reference a dataset variable from params.

pyradtran.config.load_config

How the configuration is assembled.

Examples

Three time steps at one location:

>>> import pandas as pd
>>> import xarray as xr
>>> import pyradtran  # registers ds.pyradtran
>>> ds = xr.Dataset(
...     coords={
...         "time": pd.date_range("2025-06-21T08:00", periods=3, freq="4h"),
...         "latitude": ("time", [61.0, 61.0, 61.0]),
...         "longitude": ("time", [22.0, 22.0, 22.0]),
...     }
... )
>>> type(ds.pyradtran).__name__
'PyRadtranAccessor'

Preview the input file, then run:

>>> print(ds.pyradtran.explain(config_path="config/quickstart.yaml"))  
rte_solver twostr                                                   # config
mol_abs_param lowtran per_nm                                        # config
...
>>> result = ds.pyradtran.run(config_path="config/quickstart.yaml")  
>>> result.edir.dims  
('time', 'wavelength', 'altitude')
