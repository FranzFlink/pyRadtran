pyradtran.io.RadiosondeAtmosphereGenerator#

class RadiosondeAtmosphereGenerator[source]#

Bases: object

Fetch and format radiosonde soundings for libRadtran.

Finds the closest active station and the sounding nearest in time in the Integrated Global Radiosonde Archive (IGRA 2, through the optional siphon package) and writes the profile in the three-column format of the radiosonde option of uvspec (pressure, temperature, relative humidity).

All methods are static and need network access. Import the class from pyradtran.io.

See also

ERA5AtmosphereGenerator

Atmosphere from reanalysis.

pyradtran.utils.RadiosondeFinder

Look-up of files already on disk.

Examples

Download the sounding closest to a measurement under a name RadiosondeFinder recognises (date and seconds of day):

>>> from datetime import datetime
>>> from pyradtran.io import RadiosondeAtmosphereGenerator
>>> path = RadiosondeAtmosphereGenerator.create_radiosonde_atmosphere_file(  
...     datetime(2022, 3, 28, 12, 0), 78.92, 11.93,
...     "radiosonde/20220328_43200SOD.dat",
... )

static find_closest_active_stations(stations_df, lat, lon, n=5)[source]#

Return the n closest active radiosonde stations.

A station is active when its last_year is the current (UTC) year or the year before.

Parameters:

  • stations_df (pandas.DataFrame) – Output of get_station_list(); needs at least the columns latitude, longitude and last_year.

  • lat (float) – Target location in degrees north / east.

  • lon (float) – Target location in degrees north / east.

  • n (int, default 5) – Maximum number of stations to return.

Returns:

pandas.DataFrame – The matching rows of stations_df (a copy) with an added distance_km column, sorted by increasing distance. Empty when no station is active.

Notes

Distances are great-circle distances (haversine formula) on a sphere of radius \(R = 6371\) km:

\[a = \sin^2\frac{\Delta\varphi}{2} + \cos\varphi_1 \cos\varphi_2\, \sin^2\frac{\Delta\lambda}{2}, \qquad d = 2R\,\operatorname{atan2}\!\left(\sqrt{a}, \sqrt{1-a}\right)\]

with latitudes \(\varphi\) and longitudes \(\lambda\) in radians.

Examples

>>> from datetime import datetime, timezone
>>> import pandas as pd
>>> from pyradtran.io import RadiosondeAtmosphereGenerator
>>> this_year = datetime.now(timezone.utc).year
>>> stations = pd.DataFrame(
...     {
...         "id": ["A", "B", "C"],
...         "name": ["NY-ALESUND", "TROMSO", "LINDENBERG"],
...         "latitude": [78.92, 69.68, 52.21],
...         "longitude": [11.93, 18.94, 14.12],
...         "last_year": [this_year, this_year, 1990],
...     }
... )
>>> near = RadiosondeAtmosphereGenerator.find_closest_active_stations(
...     stations, lat=78.0, lon=15.0, n=2
... )
>>> near[["name", "distance_km"]].round(1)
         name  distance_km
0  NY-ALESUND        123.0
1      TROMSO        932.6
static get_closest_sounding(target_dt, lat, lon, max_hours=24.0)[source]#

Retrieve the radiosonde sounding nearest in space and time.

Requires the siphon package and network access.

Parameters:

  • target_dt (datetime.datetime) – Target time in UTC, timezone-naive.

  • lat (float) – Target location in degrees north / east.

  • lon (float) – Target location in degrees north / east.

  • max_hours (float, default 24.0) – Accept soundings launched at most this many hours before or after target_dt.

Returns:

  • sounding_df (pandas.DataFrame or None) – Sounding profile as returned by siphon’s IGRAUpperAir.request_data (columns include pressure in hPa, height in m, temperature and dewpoint in °C).

  • header (pandas.DataFrame or None) – Sounding header as returned by siphon.

  • header_text (str or None) – One-line summary of the form "<station name> at <YYYY-mm-dd HH:MM> UTC with distance <d> km".

  • All three are *None if the station list cannot be loaded, no*

  • active station exists, or none of the candidates has data.

Raises:

InputGenerationError – If siphon is not installed.

Notes

The five closest active stations (find_closest_active_stations()) are tried in order of distance. For each station all soundings within target_dt ± max_hours are requested and the one nearest in time is returned. A nearer station is preferred over a more distant one with a better time match.

The window matters because IGRA2 files soundings at their actual launch hour, which is not always 00 or 12 UTC (Ny-Ålesund launches at about 11 UTC), and siphon matches a single requested time exactly.

Examples

>>> from datetime import datetime
>>> from pyradtran.io import RadiosondeAtmosphereGenerator
>>> df, header, text = RadiosondeAtmosphereGenerator.get_closest_sounding(  
...     datetime(2022, 3, 28, 12, 0), 78.92, 11.93
... )
static create_radiosonde_atmosphere_file(time, latitude, longitude, output_filepath)[source]#

Fetch a sounding and write it as a libRadtran radiosonde file.

Calls get_closest_sounding() and converts the profile to the format read by radiosonde <file> H2O RH.

Parameters:

  • time (datetime.datetime) – Target time in UTC, timezone-naive.

  • latitude (float) – Target location in degrees north / east.

  • longitude (float) – Target location in degrees north / east.

  • output_filepath (str or pathlib.Path) – Destination file. Parent directories are created.

Returns:

pathlib.Path – Path of the written file.

Raises:

InputGenerationError – If siphon is missing, no sounding is found, or the sounding has no level with valid pressure, temperature, dewpoint and height.

See also

pyradtran.utils.RadiosondeFinder

Finds such files by time when h2o_source is "radiosonde".

Notes

The file has three comment lines (the second names station, sounding time and distance), then one line per level with pressure (hPa), temperature (K) and relative humidity (%), top of the sounding first. Levels with missing values and duplicate pressure levels are dropped: libRadtran requires a strictly monotonic pressure grid.

Relative humidity over liquid water follows from temperature \(T\) and dewpoint \(T_d\) (both in °C) with the Magnus form of Bolton (1980) [1] for the saturation vapour pressure:

\[e_s(T) = 6.112\ \mathrm{hPa}\; \exp\!\left(\frac{17.67\,T}{T + 243.5}\right), \qquad \mathrm{RH} = 100\,\% \cdot \frac{e_s(T_d)}{e_s(T)}\]

References

[1]

Bolton, D. (1980): The computation of equivalent potential temperature. Mon. Wea. Rev., 108, 1046–1053.

Examples

>>> from datetime import datetime
>>> from pyradtran.io import RadiosondeAtmosphereGenerator
>>> path = RadiosondeAtmosphereGenerator.create_radiosonde_atmosphere_file(  
...     datetime(2022, 3, 28, 12, 0), 78.92, 11.93, "radiosonde/20220328_43200SOD.dat"
... )

Humidity conversion for −10 °C with a dewpoint of −15 °C:

>>> import numpy as np
>>> e_s = lambda t: 6.112 * np.exp(17.67 * t / (t + 243.5))
>>> round(float(100 * e_s(-15.0) / e_s(-10.0)), 1)
66.8
