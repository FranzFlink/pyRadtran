pyradtran.interface.PointOutcome#

class PointOutcome(parsed, status, detail=None, point_id='')[source]#

Bases: object

Result envelope for one simulation point.

execute_simulation_batch() with return_outcomes=True returns one per flattened input point; the status variable of a PyRadtranAccessor.run() result is built from them.

Parameters:

  • parsed (ParsedOutput or None) – Parsed uvspec output; None unless status == 0.

  • status (int) – 0: ok; 1: failed (uvspec error, timeout, or an exception while building/parsing); 2: skipped because time, latitude or longitude was missing/NaN.

  • detail (str, optional) – Failure description: uvspec stderr (prefixed with the path of the kept input file), the exception text, or the skip reason. None for successful points.

  • point_id (str) – "<YYYYmmdd_HHMMSS>_<lat>_<lon>_<index>" for points that ran, "point_<index>" for skipped ones.

Examples

>>> from pyradtran.interface import PointOutcome
>>> skipped = PointOutcome(None, 2, "NaN coordinates", "point_7")
>>> skipped.status, skipped.detail
(2, 'NaN coordinates')

Outcomes of a batch (config and ds as in execute_simulation_batch()):

>>> outcomes = execute_simulation_batch(  
...     config, ds, return_outcomes=True, show_progress=False
... )
>>> [(o.point_id, o.status) for o in outcomes]  
[('20250621_080000_61.00_22.00_0', 0),
 ('20250621_120000_61.00_22.00_1', 0),
 ('20250621_160000_61.00_22.00_2', 0)]
