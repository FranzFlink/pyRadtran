static from_era5_dataset(ds, time=None, lat=None, lon=None, cloud_variables=None, altitude_levels_km=None, lwc_threshold=0.0001, iwc_threshold=0.0001, default_r_eff_water=10.0, default_r_eff_ice=20.0, pressure_levels=None, geopotential_var=None)[source]#

Extract cloud layers from an ERA5 xarray.Dataset.

Normalises the dataset (normalize_era5()), selects one column (select_profile()), converts it with cloud_profiles() and returns the profiles as CloudLayer objects. Layer boundaries lie midway between the ERA5 levels, so the layers tile the cloudy part of the column.

Parameters:

  • ds (xarray.Dataset) – ERA5 dataset on pressure levels in any naming flavour normalize_era5() understands (CDS short names, ARCO long names, time or valid_time, pressure in hPa or Pa). Needs temperature and at least one of liquid / ice water content (kg kg-1).

  • time (datetime.datetime, str or numpy.datetime64, optional) – Time step to select (nearest). None takes the first time step.

  • lat (float, optional) – Position of the column (nearest grid point). Required when ds has a latitude or longitude dimension.

  • lon (float, optional) – Position of the column (nearest grid point). Required when ds has a latitude or longitude dimension.

  • cloud_variables (dict of str, optional) – Dataset variable names, for datasets with names normalize_era5 does not know. Keys: "lwc", "iwc", "temp", "z"; e.g. {"lwc": "LWC", "temp": "T"}. A phase whose key ("lwc" / "iwc") is missing from a dict given here is switched off; "temp" and "z" default to "t" and "z". A "cc" entry is accepted and ignored.

  • altitude_levels_km (numpy.ndarray, optional) – Altitude (km) of each pressure level, in the dataset’s own level order. Overrides the geopotential variable.

  • lwc_threshold (float, default 1e-4) – A level counts as liquid cloud when its LWC is greater than this value (g m-3).

  • iwc_threshold (float, default 1e-4) – Same for the IWC (g m-3).

  • default_r_eff_water (float, default 10.0) – Effective radius assigned to liquid layers (µm).

  • default_r_eff_ice (float, default 20.0) – Effective radius assigned to ice layers (µm).

  • pressure_levels (str, optional) – Name of the pressure coordinate, if it is not one of pressure_level, level, plev, isobaricInhPa.

  • geopotential_var (str, optional) – Name of the geopotential variable; takes precedence over cloud_variables["z"].

Returns:

list of CloudLayer – Liquid layers (iwc_g_m3 = 0) and ice layers (lwc_g_m3 = 0), sorted by base altitude. Empty when no level exceeds a threshold.

Raises:

ValueError – If ds has spatial dimensions and lat or lon is None, if it has no pressure-level coordinate, or if it has no temperature variable (needed for the air density).

See also

generate_cloud_file_from_era5

One-step convenience wrapper.

pyradtran.era5.cloud_profiles

The conversion used here; its Notes describe water content, altitudes and layer boundaries.

Notes

  • One layer per phase. A level with liquid and ice yields two layers with the same boundaries, each with its own effective radius.

  • Within each phase the layers are contiguous from the lowest to the highest level above the threshold; levels in between keep their own (sub-threshold) content, and levels with exactly zero content are left out.

  • The water contents are grid-box means, not divided by the cloud cover. cloud_fraction of the returned layers is always 1; the ERA5 cloud cover cc is not read.

  • Without a geopotential variable (and without altitude_levels_km) the altitudes are a rough estimate from pressure with a constant 7 km scale height.

Examples

A synthetic single-column ERA5 cube: liquid water at 850 and 925 hPa, a little ice at 500 hPa.

>>> import numpy as np
>>> import xarray as xr
>>> from pyradtran.clouds import CloudGenerator
>>> dims = ("time", "pressure_level", "latitude", "longitude")
>>> def column(values):
...     return (dims, np.reshape(values, (1, 5, 1, 1)))
>>> era5 = xr.Dataset(
...     {
...         "t": column([252.0, 268.0, 276.0, 280.0, 284.0]),
...         "z": column([54000.0, 29500.0, 14500.0, 7500.0, 1000.0]),
...         "clwc": column([0.0, 0.0, 2.0e-4, 3.0e-4, 0.0]),
...         "ciwc": column([2.0e-5, 0.0, 0.0, 0.0, 0.0]),
...     },
...     coords={
...         "time": np.array(["2024-07-15T12"], dtype="datetime64[ns]"),
...         "pressure_level": [500.0, 700.0, 850.0, 925.0, 1000.0],
...         "latitude": [78.0],
...         "longitude": [15.0],
...     },
... )
>>> era5["z"].attrs["units"] = "m2 s-2"
>>> layers = CloudGenerator.from_era5_dataset(era5, lat=78.0, lon=15.0)
>>> for layer in layers:
...     print(
...         f"{layer.z_bottom_km:.3f}-{layer.z_top_km:.3f} km  "
...         f"LWC {layer.lwc_g_m3:.3f}  IWC {layer.iwc_g_m3:.4f}  "
...         f"r_eff {layer.r_eff_um:.0f}"
...     )
0.433-1.122 km  LWC 0.345  IWC 0.0000  r_eff 10
1.122-2.243 km  LWC 0.215  IWC 0.0000  r_eff 10
4.257-6.756 km  LWC 0.000  IWC 0.0138  r_eff 20

static from_simple_parameters(z_base_km, z_top_km, lwc_g_m3=0.1, iwc_g_m3=0.0, r_eff_um=10.0, cloud_fraction=1.0, n_layers=1)[source]#

Create uniform cloud layers from basic parameters.

Splits z_base_km … z_top_km into n_layers sub-layers of equal thickness with the same microphysical values.

Parameters:

  • z_base_km (float) – Cloud base altitude (km above sea level).

  • z_top_km (float) – Cloud top altitude (km above sea level).

  • lwc_g_m3 (float, default 0.1) – Liquid water content (g m-3). The default is non-zero: pass lwc_g_m3=0.0 for a pure ice cloud.

  • iwc_g_m3 (float, default 0.0) – Ice water content (g m-3).

  • r_eff_um (float, default 10.0) – Effective droplet / crystal radius (µm).

  • cloud_fraction (float, default 1.0) – Cloud fraction (0–1); stored on the layers but not used by CloudFileWriter.

  • n_layers (int, default 1) – Number of sub-layers to create.

Returns:

list of CloudLayer – n_layers contiguous layers ordered from bottom to top.

Raises:

ValueError – If n_layers < 1, or any value fails the CloudLayer validation (z_base_km >= z_top_km, negative water content, non-positive radius, cloud fraction outside [0, 1]).

See also

CloudFileWriter.write_water_cloud_file

Write layers to disk.

CloudFileWriter.write_ice_cloud_file

Ice counterpart.

Notes

The sub-layers are identical, so n_layers does not change the cloud uvspec sees (the file only gains one row per internal boundary); it is a starting point for editing single layers.

For orientation (pyRadtran computes none of this), the liquid water path of the cloud is

\[\mathrm{LWP} = \int_{z_\mathrm{base}}^{z_\mathrm{top}} \mathrm{LWC}\,\mathrm{d}z = \mathrm{LWC}\,(z_\mathrm{top} - z_\mathrm{base})\]

and a common rule of thumb for the visible optical thickness of a liquid cloud (geometric-optics limit, extinction efficiency of 2) is

\[\tau \approx \frac{3\,\mathrm{LWP}}{2\,\rho_w\,r_\mathrm{eff}},\]

with the density of liquid water \(\rho_w = 1000\) kg m-3. A 1 km thick cloud with 0.3 g m-3 and \(r_\mathrm{eff}\) = 10 µm has LWP = 300 g m-2 and \(\tau \approx 45\). The optical thickness uvspec actually uses follows from the selected wc_properties / ic_properties parameterisation.

Examples

>>> from pyradtran.clouds import CloudGenerator
>>> layers = CloudGenerator.from_simple_parameters(
...     z_base_km=1.0, z_top_km=2.0, lwc_g_m3=0.3, n_layers=4
... )
>>> len(layers)
4
>>> [(layer.z_bottom_km, layer.z_top_km) for layer in layers]
[(1.0, 1.25), (1.25, 1.5), (1.5, 1.75), (1.75, 2.0)]
>>> layers[0]
CloudLayer(z_bottom_km=1.0, z_top_km=1.25, lwc_g_m3=0.3, iwc_g_m3=0.0, r_eff_um=10.0, cloud_fraction=1.0)

Liquid water path in g m-2 (thickness in km × 1000 m × g m-3):

>>> sum(
...     layer.lwc_g_m3 * (layer.z_top_km - layer.z_bottom_km) * 1000.0
...     for layer in layers
... )
300.0

A stratus deck below a cirrus layer, drawn from the layer lists:

from pyradtran.clouds import CloudGenerator

stratus = CloudGenerator.from_simple_parameters(
    1.0, 2.0, lwc_g_m3=0.3, r_eff_um=10.0, n_layers=4
)
cirrus = CloudGenerator.from_simple_parameters(
    8.0, 9.5, lwc_g_m3=0.0, iwc_g_m3=0.02, r_eff_um=30.0, n_layers=3
)

fig, ax = plt.subplots(figsize=(5.5, 4.2))
for layers, attr, color, label in (
    (stratus, "lwc_g_m3", "C0", "liquid, $r_{eff}$ = 10 µm"),
    (cirrus, "iwc_g_m3", "C1", "ice, $r_{eff}$ = 30 µm"),
):
    for k, layer in enumerate(layers):
        ax.barh(
            layer.z_bottom_km,
            getattr(layer, attr),
            height=layer.z_top_km - layer.z_bottom_km,
            align="edge",
            color=color,
            alpha=0.4,
            edgecolor=color,
            label=label if k == 0 else None,
        )
ax.set_xlabel("water content (g m$^{-3}$)")
ax.set_ylabel("altitude (km)")
ax.set_ylim(0, 11)
ax.legend()
plt.tight_layout()
