pyradtran.channels.brightness_temperature#

brightness_temperature(radiance, wavelength_nm, radiance_units='mW m-2 nm-1 sr-1')[source]#

Convert spectral radiance to brightness temperature (K).

The brightness temperature is the temperature at which a blackbody emits the given radiance at the given wavelength (the inverse of the Planck function).

Parameters:

  • radiance (array-like or xarray.DataArray) – Spectral radiance \(L_\lambda\), e.g. the uu variable of a thermal simulation.

  • wavelength_nm (float or array-like) – Wavelength in nanometres. Must broadcast against radiance; for channel-averaged radiances use the channel’s central (or effective) wavelength.

  • radiance_units ({"mW m-2 nm-1 sr-1", "W m-2 nm-1 sr-1"}) – Units of radiance, which must be per nanometre. The Notes list which uvspec settings produce which unit.

Returns:

numpy.ndarray – Brightness temperature in K, same shape as the broadcast inputs. Coordinates of an xarray.DataArray input are dropped; wrap the result with xarray.DataArray.copy() (data=...) to keep them (see Examples).

Raises:

ValueError – If radiance_units is not one of the supported unit strings.

See also

convolve_channels

Band-average spectral radiances first.

Notes

The spectral radiance of a blackbody at temperature \(T\) is

\[B_\lambda(T) = \frac{2 h c^2}{\lambda^5}\, \frac{1}{\exp\!\left(\dfrac{h c}{\lambda k_B T}\right) - 1}\]

Solving \(B_\lambda(T_b) = L_\lambda\) for the temperature gives

\[T_b = \frac{c_2}{\lambda\, \ln\!\left(1 + \dfrac{c_1}{\lambda^5 L_\lambda}\right)}, \qquad c_1 = 2 h c^2, \quad c_2 = \frac{h c}{k_B}\]

with the CODATA 2018 values of \(h\), \(c\) and \(k_B\). The logarithm is evaluated with numpy.log1p(), so the conversion stays accurate in the Rayleigh–Jeans limit (\(c_1 / \lambda^5 L_\lambda \ll 1\)).

The unit uvspec writes depends on the source:

  • source thermal: by default uvspec reports thermal quantities per spectral band (1 cm-1 wide unless changed), not per nanometre. Add params={"output_process": "per_nm"} to get W m-2 nm-1 sr-1 and pass radiance_units="W m-2 nm-1 sr-1".

  • source solar: the unit follows the solar spectrum file. The spectra shipped with libRadtran are in mW m-2 nm-1, hence the default.

For brightness temperatures at the simulated resolution, uvspec can do the inversion itself: params={"output_quantity": "brightness"} returns every radiance and irradiance column in kelvin. Use this function to post-process radiances first (channel convolution, window corrections, noise) and convert afterwards.

The conversion is monochromatic. Applied to a band-averaged radiance with the channel’s central wavelength, it is a good approximation for narrow channels (width \(\lesssim 1\) µm in the thermal window). For broad channels use an effective wavelength or a band-correction fit.

Examples

A radiance of 7.045 mW m-2 nm-1 sr-1 at 10.5 µm corresponds to a 280 K blackbody:

>>> from pyradtran import brightness_temperature
>>> float(brightness_temperature(7.045267, 10500.0).round(2))
280.0

Several channels in one call:

>>> brightness_temperature([5.0, 7.5, 10.0], [8600.0, 10800.0, 12000.0]).round(1)
array([268.6, 283.9, 308.3])

After a thermal simulation with instrument channels (output_process per_nm gives radiances in W per nanometre; center_nm holds the central wavelength of each channel):

>>> channel_ds = ds.pyradtran.run(  
...     config_path="config/thermal_spectral.yaml",
...     params={"output_process": "per_nm"},
...     channels=srf,
... )
>>> tb = channel_ds["uu"].copy(  
...     data=brightness_temperature(
...         channel_ds["uu"], channel_ds["center_nm"], "W m-2 nm-1 sr-1"
...     )
... )
>>> tb.attrs["units"] = "K"

The Planck curves being inverted, in the default radiance units:

from pyradtran import brightness_temperature

h, c, kB = 6.62607015e-34, 2.99792458e8, 1.380649e-23

def planck(wl_nm, T):
    lam = wl_nm * 1e-9
    return 2 * h * c**2 / lam**5 / np.expm1(h * c / (lam * kB * T)) * 1e-6

wl = np.linspace(4000.0, 20000.0, 400)
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(8.5, 3.6))
for T in (220, 240, 260, 280, 300):
    ax1.plot(wl / 1e3, planck(wl, T), label=f"{T} K")
ax1.set_xlabel("wavelength (µm)")
ax1.set_ylabel("$B_\\lambda$ (mW m$^{-2}$ nm$^{-1}$ sr$^{-1}$)")
ax1.set_title("Planck function")
ax1.legend(fontsize=8)

L = np.linspace(0.5, 12.0, 200)
for wl_um in (8.6, 10.8, 12.0):
    ax2.plot(L, brightness_temperature(L, wl_um * 1e3), label=f"{wl_um} µm")
ax2.set_xlabel("radiance (mW m$^{-2}$ nm$^{-1}$ sr$^{-1}$)")
ax2.set_ylabel("$T_b$ (K)")
ax2.set_title("brightness_temperature()")
ax2.legend(fontsize=8)
