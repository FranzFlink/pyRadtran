pyradtran.channels.convolve_channels

Contents

  • convolve_channels()

pyradtran.channels.convolve_channels#

convolve_channels(result, srf, keep_spectral=False)[source]#

SRF-average all spectral variables onto a channel dimension.

Every variable with a wavelength dimension is replaced by its response-weighted band average, one value per instrument channel.

Parameters:

  • result (xarray.Dataset) – Spectral simulation result with a wavelength dimension (nm), e.g. the return value of run().

  • srf (xarray.DataArray) – Spectral response, dims (channel, wavelength) with wavelength in nm. Interpolated linearly onto the result’s wavelength grid, with zero response outside the SRF’s own grid. Need not be normalised.

  • keep_spectral (bool, default False) – Keep the original spectral variables under <name>_spectral.

Returns:

xarray.Dataset – Channel-space dataset: the wavelength dimension is replaced by channel. Variables without a wavelength dimension (e.g. status) pass through unchanged, as do the dataset attributes.

Raises:

ValueError – If result has no wavelength dimension, or a channel’s SRF does not overlap the simulated wavelength range (its integral would be zero).

See also

brightness_temperature

Convert channel radiances to temperatures.

pyradtran.interface.PyRadtranAccessor.run

channels= applies this function to the simulation output.

Notes

For a spectral quantity \(X(\lambda)\) and the response \(\varphi_c(\lambda)\) of channel \(c\), the channel value is

\[\bar{X}_c = \frac{\int X(\lambda)\,\varphi_c(\lambda)\, \mathrm{d}\lambda} {\int \varphi_c(\lambda)\,\mathrm{d}\lambda}\]

Both integrals use the trapezoidal rule on the result’s wavelength grid. The output keeps the units of the input: a spectral radiance in mW m-2 nm-1 sr-1 stays a band-mean spectral radiance, as brightness_temperature() expects.

The simulated grid must resolve the SRF. With a coarse mol_abs_param (e.g. reptran coarse) and a narrow channel, few grid points carry weight and the band average becomes noisy.

Examples

A linear spectrum at two time steps, convolved with three Gaussian channels:

>>> import numpy as np
>>> import xarray as xr
>>> from pyradtran import convolve_channels
>>> wl = np.arange(8000.0, 13001.0, 10.0)
>>> result = xr.Dataset(
...     {"uu": (("time", "wavelength"), np.outer([1.0, 2.0], wl / 1000.0))},
...     coords={"time": [0, 1], "wavelength": wl},
... )
>>> centres = xr.DataArray([8600.0, 10800.0, 12000.0], dims="channel")
>>> srf = np.exp(-0.5 * ((result.wavelength - centres) / 200.0) ** 2)
>>> srf = srf.assign_coords(channel=["8.6um", "10.8um", "12.0um"])
>>> channel_ds = convolve_channels(result, srf)
>>> channel_ds.uu.dims
('time', 'channel')
>>> channel_ds.uu.round(2).values
array([[ 8.6, 10.8, 12. ],
       [17.2, 21.6, 24. ]])

Keep the spectrum next to the channel values:

>>> sorted(convolve_channels(result, srf, keep_spectral=True).data_vars)
['uu', 'uu_spectral']

A channel outside the simulated range raises:

>>> convolve_channels(result, srf.assign_coords(wavelength=wl + 9000.0))
Traceback (most recent call last):
    ...
ValueError: SRF for channel(s) ['8.6um', '10.8um', '12.0um'] has no overlap with the result wavelength grid (8000.0–13000.0 nm); convolution would divide by zero

A thermal spectrum with an ozone-like band and three imager channels:

from pyradtran import convolve_channels

wl = np.arange(7500.0, 13501.0, 5.0)
# smooth Planck-like continuum with an ozone-like absorption band
spec = 7.0 - 1.5e-7 * (wl - 10000.0) ** 2
spec -= 2.5 * np.exp(-0.5 * ((wl - 9600.0) / 180.0) ** 2)
result = xr.Dataset({"uu": ("wavelength", spec)}, coords={"wavelength": wl})

centres = xr.DataArray([8600.0, 9600.0, 11500.0], dims="channel")
srf = np.exp(-0.5 * ((result.wavelength - centres) / 250.0) ** 2)
srf = srf.assign_coords(channel=["8.6 µm", "9.6 µm", "11.5 µm"])
channels = convolve_channels(result, srf)

fig, ax = plt.subplots()
ax.plot(wl / 1e3, spec, color="0.25", label="spectral radiance")
for i, name in enumerate(srf.channel.values):
    colour = f"C{i}"
    ax.fill_between(wl / 1e3, srf.isel(channel=i) * 2.0, alpha=0.25,
                    color=colour, label=f"SRF {name} (scaled)")
    ax.plot(centres[i] / 1e3, channels.uu[i], "o", color=colour, ms=8)
ax.set_xlabel("wavelength (µm)")
ax.set_ylabel("radiance (mW m$^{-2}$ nm$^{-1}$ sr$^{-1}$)")
ax.set_title("dots: channel-averaged radiance")
ax.legend(fontsize=8, ncol=2)
