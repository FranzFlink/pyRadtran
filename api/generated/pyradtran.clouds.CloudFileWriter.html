pyradtran.clouds.CloudFileWriter#

class CloudFileWriter[source]#

Bases: object

Persist CloudLayer sequences as libRadtran .dat files.

One static method per phase:

  • write_water_cloud_file() → wc_file 1D

  • write_ice_cloud_file() → ic_file 1D

Both write a three-column ASCII table (altitude in km, water content in g m-3, effective radius in µm), top down, with rows at the layer boundaries so that uvspec sees exactly the given layers. The format is described in write_water_cloud_file().

See also

CloudGenerator

Build CloudLayer lists from data or parameters.

static write_water_cloud_file(cloud_layers, output_path, include_zero_layers=None, altitude_resolution_km=None)[source]#

Write a water-cloud .dat file for libRadtran.

Three columns, altitude (km), liquid water content (g m-3) and effective radius (µm), top down, with rows at the layer boundaries.

Parameters:

  • cloud_layers (list of CloudLayer) – Layers to write, in any order. Only layers with lwc_g_m3 > 0 are used.

  • output_path (str or pathlib.Path) – Destination file. Parent directories are created; an existing file is overwritten.

  • include_zero_layers (optional) – Deprecated and ignored (the file is written at the exact layer boundaries); passing either emits a DeprecationWarning.

  • altitude_resolution_km (optional) – Deprecated and ignored (the file is written at the exact layer boundaries); passing either emits a DeprecationWarning.

Returns:

pathlib.Path – output_path as a Path.

Raises:

ValueError – If two liquid layers overlap.

See also

write_ice_cloud_file

Same for iwc_g_m3.

pyradtran.era5.cloud_profiles

ERA5 cloud profiles as dicts.

Notes

File format. Two comment lines, then rows formatted as %10.6f %10.6f %8.3f, highest altitude first:

Column

Quantity

Unit

1

altitude z

km

2

liquid water content

g m-3

3

effective radius

µm

Rows. libRadtran reads the value in a wc_file 1D row as the property of the layer between that altitude and the next row above; the value in the topmost row is not used. Going through the layers top down, the writer emits

  • a row with zero LWC at the layer top, unless the layer above ends exactly there, and

  • a row at the layer base with the layer’s LWC and effective radius.

uvspec then sees exactly the CloudLayer list: no cloud above the highest top, in the gaps, or below the lowest base. Boundaries are compared after rounding to the file resolution of 10-6 km, so sub-layers whose boundaries differ only by floating-point rounding count as touching.

cloud_fraction is not used. When no layer contains liquid water, a warning is logged and a cloud-free placeholder (two zero rows at 1 and 0 km) is written.

Examples

>>> import pathlib, tempfile
>>> from pyradtran.clouds import CloudFileWriter, CloudGenerator
>>> tmp = tempfile.TemporaryDirectory()
>>> out = pathlib.Path(tmp.name)
>>> layers = CloudGenerator.from_simple_parameters(
...     z_base_km=1.0, z_top_km=1.5, lwc_g_m3=0.3, r_eff_um=8.0
... )
>>> path = CloudFileWriter.write_water_cloud_file(layers, out / "wc.dat")
>>> print(path.read_text(), end="")
#        z        LWC    R_eff
#       (km)    (g/m^3)     (um)
  1.500000   0.000000    8.000
  1.000000   0.300000    8.000

libRadtran reads this as 0.3 g m-3 from 1.0 to 1.5 km. Two separate decks, the lower one made of two touching layers:

>>> from pyradtran.clouds import CloudLayer
>>> decks = [
...     CloudLayer(1.0, 1.5, lwc_g_m3=0.2),
...     CloudLayer(1.5, 2.0, lwc_g_m3=0.4),
...     CloudLayer(2.5, 3.0, lwc_g_m3=0.1, r_eff_um=6.0),
... ]
>>> path = CloudFileWriter.write_water_cloud_file(decks, out / "wc.dat")
>>> print(path.read_text(), end="")
#        z        LWC    R_eff
#       (km)    (g/m^3)     (um)
  3.000000   0.000000    6.000
  2.500000   0.100000    6.000
  2.000000   0.000000   10.000
  1.500000   0.400000   10.000
  1.000000   0.200000   10.000

The zero row at 2.0 km keeps the gap up to 2.5 km cloud-free. Overlapping layers are refused:

>>> CloudFileWriter.write_water_cloud_file(
...     [CloudLayer(1.0, 2.0, lwc_g_m3=0.2), CloudLayer(1.5, 2.5, lwc_g_m3=0.1)],
...     out / "wc.dat",
... )
Traceback (most recent call last):
    ...
ValueError: Cloud layers overlap: a layer with top at 2.0 km lies above the base (1.5 km) of the layer above it
>>> tmp.cleanup()

Use the file in a run:

>>> result = ds.pyradtran.run(  
...     config_path=cfg, params={"wc_file": f"1D {path}"}
... )
static write_ice_cloud_file(cloud_layers, output_path, include_zero_layers=None, altitude_resolution_km=None)[source]#

Write an ice-cloud .dat file for libRadtran.

Same format and row layout as write_water_cloud_file(), for the layers with iwc_g_m3 > 0.

Parameters:

  • cloud_layers (list of CloudLayer) – Layers to write, in any order. Only layers with iwc_g_m3 > 0 are used.

  • output_path (str or pathlib.Path) – Destination file. Parent directories are created; an existing file is overwritten.

  • include_zero_layers (optional) – Deprecated and ignored (the file is written at the exact layer boundaries); passing either emits a DeprecationWarning.

  • altitude_resolution_km (optional) – Deprecated and ignored (the file is written at the exact layer boundaries); passing either emits a DeprecationWarning.

Returns:

pathlib.Path – output_path as a Path.

Raises:

ValueError – If two ice layers overlap.

See also

write_water_cloud_file

File format and row layout.

Notes

Columns: altitude (km), ice water content (g m-3) and effective radius (µm), highest altitude first, formatted as %10.6f %10.6f %8.3f.

Whether the effective radius of each layer is valid depends on the ice parameterisation chosen with ic_properties. When no layer contains ice, a cloud-free placeholder (two zero rows at 1 and 0 km) is written.

Examples

>>> import pathlib, tempfile
>>> from pyradtran.clouds import CloudFileWriter, CloudGenerator
>>> tmp = tempfile.TemporaryDirectory()
>>> out = pathlib.Path(tmp.name)
>>> cirrus = CloudGenerator.from_simple_parameters(
...     8.0, 9.0, lwc_g_m3=0.0, iwc_g_m3=0.002, r_eff_um=30.0
... )
>>> path = CloudFileWriter.write_ice_cloud_file(cirrus, out / "ic.dat")
>>> print(path.read_text(), end="")
#        z        IWC    R_eff
#       (km)    (g/m^3)     (um)
  9.000000   0.000000   30.000
  8.000000   0.002000   30.000

Layers without ice give a cloud-free placeholder:

>>> stratus = CloudGenerator.from_simple_parameters(1.0, 2.0, lwc_g_m3=0.3)
>>> path = CloudFileWriter.write_ice_cloud_file(stratus, out / "ic.dat")
>>> print(path.read_text(), end="")
#        z        IWC    R_eff
#       (km)    (g/m^3)     (um)
  1.000000   0.000000   30.000
  0.000000   0.000000   30.000
>>> tmp.cleanup()
