pyradtran.core.Simulation#

class Simulation(config)[source]#

Bases: object

Low-level wrapper around a single uvspec execution.

Each run_simulation() call writes one input file, runs uvspec on it and returns the path of the raw output file. dry_run() and build_input_lines() build the same input without running it. The only per-point state is the failure diagnostics below, so one instance can serve many points.

Parameters:

config (SimulationConfig) – Fully merged configuration, e.g. from load_config(). Not copied.

config#

The configuration passed in.

Type:

SimulationConfig

builder#

Turns configuration + resolved parameters into input lines.

Type:

InputFileBuilder

last_stderr#

uvspec stderr (or a timeout / launch error message) of the most recent run_simulation() call if it failed, else None.

Type:

str or None

last_failed_input#

Input file of the most recent failed run, kept on disk for post-mortem; None after a successful run.

Type:

pathlib.Path or None

radiosonde_finder#

Radiosonde lookup, present when paths.radiosonde_base is configured.

Type:

RadiosondeFinder or None

See also

pyradtran.interface.PyRadtranAccessor.run

High-level entry point.

pyradtran.interface.execute_simulation_batch

Parallel driver that creates one Simulation per point.

pyradtran.io.OutputParser

Parses the output file returned by run_simulation().

Notes

Per-point parameters are passed as resolved params: a mapping key -> (value, provenance) where key is a uvspec option name and provenance one of "config", "params-literal", "dataset-var", "unvalidated" (the PROV_* constants in pyradtran.params). ParamResolver produces this mapping from a user params dict. Values given here are not validated again. A resolved parameter replaces the configuration’s line for the same option.

Examples

>>> from datetime import datetime
>>> from pyradtran import Simulation, load_config
>>> sim = Simulation(load_config("config/quickstart.yaml"))

Preview the input file, run it and read the raw output:

>>> noon = datetime(2025, 6, 21, 12)
>>> params = {"wavelength": ("500 502", "params-literal")}
>>> text = sim.dry_run(noon, 61.0, 22.0, resolved_params=params)  
>>> out = sim.run_simulation(noon, 61.0, 22.0, resolved_params=params)  
>>> out.name  
'tmpvouk2nni.out'
>>> print(out.read_text())  # lambda edir edn eup  
  500.000  1.165645e+03  1.452510e+02  2.270538e+02
  501.000  1.146696e+03  1.416279e+02  2.231443e+02
  502.000  1.134968e+03  1.389458e+02  2.206483e+02

A failing run returns None and keeps the diagnostics:

>>> bad = {"rte_solver": ("nonsense", "unvalidated")}
>>> sim.run_simulation(noon, 61.0, 22.0, resolved_params=bad) is None  
True
>>> print(sim.last_stderr)  
Option rte_solver nonsense  has an invalid argument 1 on line 14: nonsense
Error in input file! Please check your input file and retry!
>>> sim.last_failed_input.name  
'tmpwzgv161d.inp'

Build the provenance-tagged input lines for one point.

Returns one InputLine (keyword, text, provenance) per uvspec option, in file order. dry_run() and run_simulation() use it.

Parameters:

  • dt (datetime.datetime) – Simulation date/time (UTC). Sets day_of_year and, for solar runs without an explicit sza, the solar zenith angle.

  • latitude (float) – Location in degrees north / east.

  • longitude (float) – Location in degrees north / east.

  • resolved_params (dict, optional) – key -> (value, provenance) mapping from pyradtran.params.ParamResolver.resolve_point(). Wins over the configuration and over the deprecated arguments.

  • era5_atmosphere_file (pathlib.Path, optional) – Radiosonde-format atmosphere file (see pyradtran.era5.write_atmosphere_file()). Takes precedence over a radiosonde lookup.

  • override_albedo (float, optional) – Deprecated; use resolved_params.

  • override_surface_temperature (float, optional) – Deprecated; use resolved_params.

  • override_altitude_km (float, optional) – Deprecated; use resolved_params.

  • override_surface_type (int, optional) – Deprecated; use resolved_params.

  • parameter_overrides (dict, optional) – Deprecated; use resolved_params.

Returns:

list of InputLine – The ordered input lines.

Warns:

DeprecationWarning – If any override_* argument or parameter_overrides is used.

See also

dry_run

The same lines rendered as annotated text.

pyradtran.input_builder.InputFileBuilder.build

Does the work.

Notes

simulation_defaults.parameter_overrides from the configuration are applied first (provenance config), then the deprecated arguments, then resolved_params. With h2o_source: radiosonde and a configured paths.radiosonde_base, the radiosonde file closest in time to dt is included.

Examples

>>> from datetime import datetime
>>> from pyradtran import Simulation, load_config
>>> sim = Simulation(load_config("config/quickstart.yaml"))  
>>> lines = sim.build_input_lines(  
...     datetime(2025, 6, 21, 12), 61.0, 22.0,
...     resolved_params={"albedo": (0.8, "params-literal")},
... )
>>> lines[0]  
InputLine(keyword='rte_solver', text='rte_solver twostr', provenance='config')
>>> [ln.text for ln in lines if ln.provenance != "config"]  
['albedo 0.8']

  • resolved_params (dict, optional) – key -> (value, provenance) mapping, as in run_simulation().

  • era5_atmosphere_file (pathlib.Path, optional) – Radiosonde-format atmosphere file to reference.

Returns:

See also

pyradtran.interface.PyRadtranAccessor.explain

The same preview for a point of a dataset, from a user params mapping.

The same lines as objects.

Notes

Nothing is written to disk. A dict-valued wc_file / ic_file (from resolved_params or a cloud_source: parametric configuration) therefore appears as a placeholder such as wc_file 1D <generated: 2 levels, 1-2 km>. run_simulation() writes it to a temporary file and puts 1D <path> on the line.

run_simulation(dt, latitude, longitude, resolved_params=None, era5_atmosphere_file=None, override_albedo=None, override_surface_temperature=None, override_altitude_km=None, override_surface_type=None, parameter_overrides=None)[source]#

Run a single uvspec simulation.

Writes the input file for one point to paths.working_dir, pipes it into uvspec (paths.libradtran_bin) and stores stdout next to it as <name>.out.

Parameters:

  • dt (datetime.datetime) – Simulation date/time (UTC).

  • latitude (float) – Location in degrees north / east.

  • longitude (float) – Location in degrees north / east.

  • resolved_params (dict, optional) – key -> (value, provenance) mapping from pyradtran.params.ParamResolver.resolve_point(). A dict value for "wc_file" / "ic_file" is written to a temporary cloud file with format_cloud_profile() and replaced by 1D <path>. The layer of a cloud_source: parametric configuration is handled the same way (see parametric_cloud_profiles()) unless resolved_params has that key.

  • era5_atmosphere_file (pathlib.Path, optional) – Custom ERA5 atmosphere file (radiosonde format).

  • override_albedo (float, optional) – Deprecated; use resolved_params.

  • override_surface_temperature (float, optional) – Deprecated; use resolved_params.

  • override_altitude_km (float, optional) – Deprecated; use resolved_params.

  • override_surface_type (int, optional) – Deprecated; use resolved_params.

  • parameter_overrides (dict, optional) – Deprecated; use resolved_params.

Returns:

pathlib.Path or None – Path to the raw uvspec output file, or None if uvspec exited with an error, timed out (execution.timeout_seconds) or could not be started. last_stderr then holds the error message and last_failed_input the kept input file.

Raises:

UvspecExecutionError – If the input file cannot be built or written (e.g. an invalid cloud-profile dict). The original exception is chained. A failing uvspec does not raise.

Warns:

DeprecationWarning – If any override_* argument or parameter_overrides is used.

See also

dry_run

Show the input file without running.

pyradtran.io.OutputParser.parse_output_file

Parse the returned file.

pyradtran.interface.execute_simulation_batch

Runs this for every point of a dataset.

Notes

With execution.cleanup_temp_files, the input file and temporary cloud files are deleted after a successful run. The output file is left for the caller to parse and remove. After a failure, the input file and its cloud files are always kept.

Examples

>>> from datetime import datetime
>>> from pyradtran import Simulation, load_config
>>> sim = Simulation(load_config("config/quickstart.yaml"))  
>>> out = sim.run_simulation(  
...     datetime(2025, 6, 21, 12), 61.0, 22.0,
...     resolved_params={"wavelength": ("500 502", "params-literal")},
... )
>>> print(out.read_text())  # lambda edir edn eup  
  500.000  1.165645e+03  1.452510e+02  2.270538e+02
  501.000  1.146696e+03  1.416279e+02  2.231443e+02
  502.000  1.134968e+03  1.389458e+02  2.206483e+02
static format_cloud_profile(data)[source]#

Format a cloud-profile dict as a libRadtran column file.

Returns the three-column text (altitude, water content, effective radius) that wc_file 1D / ic_file 1D expect. A dict-valued wc_file / ic_file parameter is converted this way before uvspec runs.

Parameters:

data (dict) –

Profile with equally long sequences under the keys

"z"

Level altitudes in km, top of atmosphere first (descending), as libRadtran requires.

"lwc" or "iwc"

Liquid or ice water content in g m-3. If both are present, "lwc" is used.

"reff"

Effective radius in µm.

Returns:

str – One line per level, z content reff with six decimals, newline-terminated. Rows keep the given order; values are neither sorted nor validated.

Raises:

  • ValueError – If "z", "reff" or both of "lwc" / "iwc" are missing.

  • RuntimeError – If the columns cannot be combined (e.g. unequal lengths).

See also

pyradtran.interface.PyRadtranAccessor.inspect_cloud_file

Preview the profile built for a point of a dataset.

pyradtran.era5.cloud_profiles

Build such dicts from ERA5.

Notes

libRadtran takes the value at level \(z_i\) as the constant content of the layer between \(z_i\) and the next level above, \(z_{i-1}\). The topmost row only closes the grid: give it zero content. The water path of a profile with levels \(z_0 > z_1 > \dots > z_n\) is

\[\mathrm{LWP} = \sum_{i=1}^{n} w_i\,(z_{i-1} - z_i)\]

(in g m-2 with \(w\) in g m-3 and \(z\) in m).

Examples

A 1 km thick liquid cloud with 0.3 g m-3 and 10 µm droplets (LWP = 300 g m-2):

>>> from pyradtran import Simulation
>>> print(
...     Simulation.format_cloud_profile(
...         {"z": [2.0, 1.0], "lwc": [0.0, 0.3], "reff": [0.0, 10.0]}
...     )
... )
2.000000 0.000000 0.000000
1.000000 0.300000 10.000000

A two-layer ice cloud from NumPy arrays:

>>> import numpy as np
>>> text = Simulation.format_cloud_profile(
...     {
...         "z": np.array([2.0, 1.5, 1.0]),
...         "iwc": np.array([0.0, 0.02, 0.01]),
...         "reff": np.array([0.0, 30.0, 25.0]),
...     }
... )
>>> text.splitlines()
['2.000000 0.000000 0.000000', '1.500000 0.020000 30.000000', '1.000000 0.010000 25.000000']

Incomplete profiles are rejected:

>>> Simulation.format_cloud_profile({"z": [2.0, 1.0], "reff": [0.0, 10.0]})
Traceback (most recent call last):
    ...
ValueError: Profile data must contain 'lwc' or 'iwc'
