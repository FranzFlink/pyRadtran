API Reference#

Everything public in pyRadtran, grouped by what you want to do. Most names are importable straight from the top-level package (from pyradtran import Var, load_config, brightness_temperature).

Tip

New here? Start with ds.pyradtran.run(), Var and load_config() — those three cover most notebooks.

Running simulations#

The ds.pyradtran accessor is registered on every xarray.Dataset as soon as pyradtran is imported.

interface.PyRadtranAccessor(xarray_obj)

xarray accessor for running libRadtran simulations (ds.pyradtran).

interface.PyRadtranAccessor.run([...])

Run uvspec for every point in the dataset.

interface.PyRadtranAccessor.explain([point, ...])

Preview the annotated uvspec input file for one point.

interface.PyRadtranAccessor.jacobian(param, ...)

Finite-difference sensitivity kernel for one scalar parameter.

interface.PyRadtranAccessor.inspect_cloud_file([...])

Preview the cloud-profile file run() would write for a point.

interface.run_pyradtran_simulation(input_file)

Run a full simulation pipeline from a CSV/NetCDF input file.

interface.execute_simulation_batch(config, ...)

Run uvspec for every point in input_ds.

core.Simulation(config)

Low-level wrapper around a single uvspec execution.

Parameters#

How values reach the uvspec input file — see Parameters & Validation.

params.Var(name)

Per-point reference to a variable of the input dataset.

params.Raw(value)

Pass a params value through without any validation.

params.describe(name[, config, schema])

Return usage, help, and documentation for one uvspec option.

params.search_options(text[, config, schema])

Return uvspec option names whose name, group, or help match text.

params.ParamSpec(keyword[, dtype, units, ...])

Declarative description of one curated uvspec parameter.

params.ParamResolver(config[, params, schema])

Resolve a user params mapping into validated per-point values.

params.get_schema(config)

Load (and memoise) the libRadtran option schema for config.

params.validate_against_schema(entry, key, value)

Validate one params entry against a schema option definition.

Configuration#

config.load_config([config_path])

Load and merge the three-layer configuration.

config.save_master_config(libradtran_bin, ...)

Write (or update) the user master config ~/.pyradtran/config.yaml.

config.create_example_config(output_path)

Write a complete example YAML config to output_path.

config.list_atmosphere_profiles()

Print a table of available atmosphere profile short names.

config.list_solar_spectra()

Print a table of available solar spectrum short names.

config.SimulationConfig(paths, ...[, ...])

Top-level configuration container.

config.SimulationDefaults([rte_solver, ...])

Physics and spectral settings (YAML section simulation_defaults).

config.PathsConfig(libradtran_bin, ...[, ...])

File-system paths required by libRadtran (YAML section paths).

config.ExecutionConfig([max_workers, ...])

Run-time execution settings (YAML section execution).

config.OutputConfig([filename_prefix, ...])

NetCDF output-file settings (YAML section output).

config.CloudParameters([enabled, ...])

Static cloud settings (YAML section simulation_defaults.clouds).

Instrument channels & brightness temperature#

channels.convolve_channels(result, srf[, ...])

SRF-average all spectral variables onto a channel dimension.

channels.brightness_temperature(radiance, ...)

Convert spectral radiance to brightness temperature (K).

Atmospheres: ERA5 and radiosondes#

era5.normalize_era5(ds)

Return ds with ERA5 variables/coordinates on canonical names.

era5.recommend_atmosphere(latitude, time)

Suggest the AFGL atmosphere_file shortname for a location/date.

era5.era5_atmosphere_file(era5_ds, latitude, ...)

Normalise, select a point and write the atmosphere file.

era5.write_atmosphere_file(profile, ...[, ...])

Write a profile as a libRadtran radiosonde atmosphere file.

era5.select_profile(ds[, latitude, ...])

Select a single vertical profile from a (normalised) ERA5 dataset.

era5.cloud_profiles(profile[, ...])

Build wc_file / ic_file profile dicts from an ERA5 column.

io.ERA5AtmosphereGenerator()

Create libRadtran-compatible atmosphere files from ERA5 data.

io.RadiosondeAtmosphereGenerator()

Fetch and format radiosonde soundings for libRadtran.

utils.RadiosondeFinder(base_path)

Locate the radiosonde file closest in time to a target datetime.

Clouds#

clouds.CloudLayer(z_bottom_km, z_top_km[, ...])

A homogeneous cloud slab between two altitudes.

clouds.CloudGenerator()

Factory for CloudLayer sequences.

clouds.CloudFileWriter()

Persist CloudLayer sequences as libRadtran .dat files.

clouds.generate_cloud_file_from_era5(...[, ...])

Write a cloud file from an ERA5 dataset in one call.

Input files#

input_builder.InputFileBuilder(config)

Build provenance-tagged uvspec input lines.

input_builder.InputLine(keyword, text, ...)

One uvspec input line with provenance.

input_builder.calculate_solar_zenith_angle(dt, ...)

Solar zenith angle (degrees) from time and location.

input_builder.effective_output_columns(config)

Columns the output_user line requests, in file order.

input_builder.effective_output_altitudes(config)

Output altitudes of a run: the zout override, else the config.

Output parsing & storage#

io.OutputParser(config[, ...])

Parse raw uvspec output files into ParsedOutput.

io.ParsedOutput(output_type, data[, ...])

One parsed uvspec output file (one simulated point).

io.OutputType(value)

Layout of a uvspec output table.

io.OutputToXarray()

Convert ParsedOutput objects to xarray.Dataset.

io.NetCDFSaver()

Save simulation results as NetCDF with provenance attributes.

io.InputDataLoader()

Load simulation input coordinates from CSV or NetCDF files.

interface.PointOutcome(parsed, status[, ...])

Result envelope for one simulation point.

interface.SimPoint(index, time, latitude, ...)

One flattened simulation point, fully resolved.

libRadtran option schema#

schema.load_schema([config, root])

Return the option schema for the local libRadtran install, cached.

schema.extract_schema(root)

Extract the option schema from <root>/src_py (no cache).

schema.find_libradtran_root(config)

Locate the libRadtran installation root from config paths.

Exceptions#

exceptions.PyRadtranError

Base exception for all pyRadtran errors.

exceptions.ConfigurationError

Raised when the configuration is unusable.

exceptions.ValidationError

Raised when a user-supplied parameter value fails validation.

exceptions.InputGenerationError

Raised when the inputs of a simulation cannot be prepared.

exceptions.UvspecExecutionError

Raised when a single uvspec simulation cannot be carried out.

exceptions.OutputParsingError

Raised when simulation output cannot be read or written.

exceptions.RadiosondeError

Reserved for radiosonde file discovery and parsing errors.
