# Interactive Notebooks

This section contains interactive Jupyter notebooks that demonstrate PyRadtran's capabilities with real-world examples and tutorials.

## Features of Our Notebooks

- **Interactive Examples**: All notebooks can be run interactively on Binder or downloaded locally
- **Real Data**: Many examples use actual atmospheric measurement data
- **Comprehensive Coverage**: From basic tutorials to advanced scientific applications
- **Copy-Paste Ready**: Code blocks are easily copyable for your own projects

## Getting Started

If you're new to PyRadtran, start with the quickstart notebook, which covers the basic workflow.

For more advanced applications, explore the atmospheric radiation examples using real measurement data from scientific campaigns.

```{note}
All notebooks can be launched interactively using the 🚀 rocket icon at the top of each page, or downloaded as `.ipynb` files for local execution.
```

## Notebook Requirements

To run these notebooks locally, you'll need:

```bash
pip install pyradtran matplotlib numpy xarray pandas netcdf4
```

Some notebooks may require additional packages which are noted at the beginning of each notebook.
