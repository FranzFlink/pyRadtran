# Configuration Gallery

The simulation configs used by the notebooks, in `book/notebooks/config/`.
Copy one, change what differs for your experiment, and pass it as
`config_path=`. libRadtran paths come from the master config
({doc}`/installation`); the fields are described in
{doc}`/guide/configuration`.
