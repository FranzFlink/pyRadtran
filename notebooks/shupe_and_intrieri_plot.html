Reproducing Shupe & Intrieri (2004)#

Shupe and Intrieri (2004, J. Climate, 17, 616–628, doi:10.1175/1520-0442(2004)017<0616:CRFOTA>2.0.CO;2) show in their Fig. 7, for a liquid cloud at −10 °C and 1 km, the liquid water path (LWP) at which the shortwave surface cooling of the cloud starts to exceed its longwave warming, as a function of solar zenith angle (SZA) and surface albedo. This notebook computes the same map with full radiative transfer: the net surface cloud radiative effect (CRE) over a grid of SZA × albedo × LWP and its zero contour for each LWP.

Atmosphere, solver and spectral ranges come from the two configs of Multi-dimensional cloud experiment (subarctic winter afglsw, disort, reptran coarse). The run takes about five minutes with 8 workers.

import logging

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import xarray as xr
from matplotlib.patches import Rectangle

import pyradtran  # registers the .pyradtran accessor
from pyradtran import Var

logging.getLogger("pyradtran").setLevel(logging.ERROR)

Parameter space#

  • SZA 30–88° and surface albedo 0–1 are dataset dimensions; the SZA is set directly through params={"sza": Var(...)} instead of being computed from time and position.

  • The cloud is a homogeneous liquid layer from 0.3 to 1.0 km (700 m thick, about −14 to −11 °C in afglsw) with 15 µm effective radius. LWC = LWP / 700 m gives 0.014–0.57 g m⁻³ for the LWP values of the paper’s figure (10–400 g m⁻²).

  • The longwave CRE does not depend on the SZA or the shortwave albedo, so the thermal run only sweeps LWP. Surface emissivity is 0.99 (albedo 0.01) and the surface temperature is the lowest level of afglsw (257.2 K).

szas = np.r_[np.arange(30, 90, 5), 88.0]       # degrees
albedos = np.round(np.arange(0, 1.01, 0.1), 2)
lwps = np.array([0, 10, 15, 20, 30, 50, 100, 200, 400.0])  # g m-2, 0 = clear sky
cbh, cth = 0.3, 1.0                                        # km
thickness_m = (cth - cbh) * 1000                           # 700 m
lwc = np.where(lwps > 0, lwps / thickness_m, np.nan)       # g m-3

ds = xr.Dataset(
    coords={
        "time": [pd.Timestamp("2024-05-01 12:00")],  # only fixes the Earth-Sun distance
        "latitude": ("time", [78.0]),
        "longitude": ("time", [0.0]),
        "lwp": lwps,
    },
    data_vars={
        "lwc": ("lwp", lwc),
        "reff": ("lwp", np.full(lwps.size, 15.0)),
        "cbh": ("lwp", np.full(lwps.size, cbh)),
        "cth": ("lwp", np.full(lwps.size, cth)),
    },
)
ds_solar = ds.assign_coords(sza=szas, albedo=albedos)
ds_solar["sza_deg"] = ds_solar.sza
ds_solar["albedo_sw"] = ds_solar.albedo
print(f"solar points: {ds_solar.sza.size * ds_solar.albedo.size * ds_solar.lwp.size}, thermal points: {ds.lwp.size}")

solar points: 1287, thermal points: 9

Run#

cloud = dict(cloud_wc_var="lwc", cloud_reff_var="reff", cloud_top_var="cth", cloud_bottom_var="cbh")
run = dict(save_to_file=False, show_progress=False)

solar = ds_solar.pyradtran.run(
    config_path="config/arctic_cloud_experiment_solar.yaml",
    params={"sza": Var("sza_deg"), "albedo": Var("albedo_sw")},
    **cloud, **run,
).isel(time=0, altitude=0)

thermal = ds.pyradtran.run(
    config_path="config/arctic_cloud_experiment_thermal.yaml",
    params={"albedo": 0.01, "sur_temperature": 257.2},
    **cloud, **run,
).isel(time=0, altitude=0)

print("failed points:", int((solar.status != 0).sum() + (thermal.status != 0).sum()))

failed points: 0

Cloud radiative effect#

CRE = cloudy minus clear-sky net irradiance at the surface, shortwave (mW m⁻² → W m⁻², units) plus longwave.

net_sw = (solar.edir + solar.edn - solar.eup) / 1e3
net_lw = thermal.edn - thermal.eup
cre_sw = (net_sw - net_sw.sel(lwp=0)).drop_sel(lwp=0)
cre_lw = (net_lw - net_lw.sel(lwp=0)).drop_sel(lwp=0)
cre = cre_sw + cre_lw

print("longwave CRE (W m-2):", cre_lw.round(1).to_pandas().to_dict())

longwave CRE (W m-2): {10.0: 43.6, 15.0: 53.9, 20.0: 60.7, 30.0: 68.3, 50.0: 73.6, 100.0: 75.2, 200.0: 75.1, 400.0: 75.0}

Zero-CRE contours#

Each line is CRE = 0 for one LWP (label, g m⁻²). Above a line (brighter surface, lower sun) that cloud warms the surface, below it the cloud cools. The rectangle is the SHEBA region marked in Fig. 7 of the paper (SZA 54–90°, albedo 0.45–0.90).

fig, ax = plt.subplots(figsize=(6.5, 5.5))
for lwp in cre.lwp.values:
    cs = cre.sel(lwp=lwp).plot.contour(x="sza", y="albedo", levels=[0], colors="k", ax=ax)
    ax.clabel(cs, fmt=f"{lwp:.0f}", fontsize=9)
ax.add_patch(Rectangle((54, 0.45), 36, 0.45, fill=False, edgecolor="C3", lw=1.5))
ax.text(72, 0.92, "SHEBA region", color="C3", ha="center")
ax.set_xlim(30, 90)
ax.set_ylim(0, 1)
ax.set_title("Net surface CRE = 0, contour labels are LWP (g m$^{-2}$)")
ax.set_xlabel("Solar zenith angle (°)")
ax.set_ylabel("Surface albedo")
ax.grid(alpha=0.3)

Comparison with the paper#

The shape agrees with Fig. 7 of Shupe and Intrieri (2004): the zero-CRE albedo rises with LWP, depends little on the SZA below about 60°, and all contours drop steeply between 70° and 85°, where the sun is too low for the shortwave cooling to matter. At low sun nearly any liquid cloud warms the surface.

The contours here lie about 0.05–0.15 lower in albedo than in the paper, so the cloud warms the surface over a wider range of conditions. The longwave CRE here saturates at about 75 W m⁻² (44 W m⁻² at 10 g m⁻², 68 W m⁻² at 30 g m⁻²), which is large because the dry subarctic-winter atmosphere emits little in clear sky. The paper used a simpler model with fixed atmospheric transmittances and a cloud at −10 °C; the cloud here is 1–4 K colder. Differences of this size are expected from the different atmosphere and radiation scheme, not a sign of an error. Reproducing Shupe & Intrieri (2004), part 2: seasonal ERA5 profiles repeats the calculation with ERA5 profiles.
