Solar validation against HALO-(AC)³ aircraft measurements#

Compares simulated broadband downwelling solar irradiance with clear-sky measurements from the HALO, P5 and P6 aircraft during HALO-(AC)³, and with the simulations published with the dataset (Becker et al., 2023). The measurements are in data/; the last plot needs seaborn.

Note

The water-vapour and temperature profiles come from HALO-(AC)³ dropsondes, converted to libRadtran radiosonde files (p T RH, one YYYYMMDD_SSSSSSOD.dat file per sonde) in radiosonde/Flight_YYYYMMDD/. These files are not redistributable and are not shipped with pyRadtran. Without them radiosonde/ is empty, no profile is found and the runs fall back to the US standard water-vapour profile.

Setup#

import pyradtran
from pyradtran import Var, load_config
import matplotlib.pyplot as plt
import numpy as np
import xarray as xr
from pathlib import Path
import pandas as pd
import logging

# Configure logging for pyradtran
logging.getLogger('pyradtran').setLevel(logging.CRITICAL)

# ── Simulation parameters ─────────────────────────────────────────────────────
# Paths come from ~/.pyradtran/config.yaml (master config);
# radiosonde_base points to the dropsonde files next to this notebook
cfg = load_config()

cfg.simulation_defaults.rte_solver           = "disort"
cfg.simulation_defaults.mol_abs_param        = "reptran medium"
cfg.simulation_defaults.source               = "solar"
cfg.simulation_defaults.wavelength_nm        = [290, 4500]
cfg.simulation_defaults.integrate_wavelength = True
cfg.simulation_defaults.h2o_source           = "radiosonde"
cfg.simulation_defaults.ozone_du             = None   # ozone from the atmosphere file
cfg.simulation_defaults.h2o_mm               = None   # use radiosonde
cfg.simulation_defaults.surface_temperature_k = 253.15
cfg.simulation_defaults.output_altitudes_km  = [0.0]
cfg.simulation_defaults.output_columns       = ["zout", "lambda", "sza", "edir", "eglo", "edn", "eup", "enet", "albedo"]
cfg.execution.max_workers                    = 8
cfg.execution.timeout_seconds               = 3600

# Dropsonde profiles (not shipped, see the note above); relative to this notebook.
# For every point the sonde closest in time is used.
cfg.paths.radiosonde_base = "radiosonde"

config_path = Path("config/halo-ac3_bbr_all_aircraft.yaml")
cfg.to_yaml(config_path)
print(f"Config saved to {config_path}")

Config saved to config/halo-ac3_bbr_all_aircraft.yaml

Data preparation#

The flight-level albedo \(F^\uparrow/F^\downarrow\) is used as surface albedo where it was measured and is below 1, otherwise 0.5. The aircraft altitude is a data variable on time, so each point is simulated at its own flight level (How pyRadtran works).

# Load CSV and convert to xarray Dataset
df = pd.read_csv('data/HALO-AC3_HALO_P5_P6_aircraft_broadband_radiation_clear_sky_with_ocean_100s.csv', parse_dates=['time'])
df = df.set_index('time')

ds = xr.Dataset.from_dataframe(df).drop_duplicates('time').sortby('time')
ds_to_sim = ds.rename({'Lat': 'latitude', 'Lon': 'longitude', 'Alt': 'altitude'})

# Use uncorrected solar flux where available
ds_to_sim['F_down_solar'].loc[{'time': ds_to_sim.F_down_solar_uncorr.notnull()}] = ds_to_sim.F_down_solar_uncorr.loc[{'time': ds_to_sim.F_down_solar_uncorr.notnull()}]

# Albedo from the measured upward/downward solar irradiance at flight level
albedo = (ds_to_sim['F_up_solar'] / ds_to_sim['F_down_solar'])
albedo = albedo.where(albedo < 1)  # Remove unphysical values > 1
ds_to_sim['albedo'] = ('time', albedo.astype(float).values)
ds_to_sim['albedo'] = ds_to_sim['albedo'].fillna(0.5)  # Default albedo for NaN values

# Aircraft altitude (m -> km) as a data variable: one output level per point
ds_to_sim['altitude'] = ds_to_sim['altitude'] / 1e3

Running simulations#

# Broadband simulation at flight level for every point
print("Running broadband simulation...")
ds_sim = ds_to_sim.pyradtran.run(
    config_path=config_path,
    return_dataset=True,
    save_to_file=True,
    output_path='data/Simulated_HALO-AC3_HALO_P5_P6_aircraft_broadband_radiation_clear_sky_with_ocean_100s.nc',
    params={'albedo': Var('albedo')},
    show_progress=False,
)

print("\nSimulation complete!")
