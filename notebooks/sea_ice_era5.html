ERA5 sea-ice profiles#

Mean ERA5 temperature and humidity profiles north of 60° N for 1980–2019, binned by season, five-year period and sea-ice cover. The result, data/era5_sea_ice_to_libradtran.nc, is read by Arctic atmosphere in a warming climate: ERA5 sea-ice profiles (trends) and Reproducing Shupe & Intrieri (2004), part 2: seasonal ERA5 profiles (atmospheres for pyRadtran). It needs gcsfs and network access.

Data and sampling#

The source is the public ARCO-ERA5 archive on Google Cloud Storage, on its coarsest grid (64 × 32 points, 5.6°, 6-hourly, 13 pressure levels), read anonymously. The archive is stored in blocks of 100 time steps (25 days). To keep the download near 2 GB, the notebook reads every fourth block, 25 days out of every 100. Because 100 days does not divide the year, the sampled days move through the calendar and all seasons are covered evenly. The download takes a few minutes and is cached in data/era5_arctic_6h_64x32_subset.nc (about 600 MB, not under version control).

The pole row (90° N) is dropped: on this grid it repeats one value 64 times.

from pathlib import Path

import gcsfs
import numpy as np
import pandas as pd
import xarray as xr

CACHE = Path("data/era5_arctic_6h_64x32_subset.nc")
OUTPUT = Path("data/era5_sea_ice_to_libradtran.nc")
URL = "gs://gcp-public-data-arco-era5/ar/1959-2022-6h-64x32_equiangular_with_poles_conservative.zarr"

if CACHE.exists():
    subset = xr.open_dataset(CACHE).load()
else:
    gcs = gcsfs.GCSFileSystem(token="anon")
    era5 = xr.open_zarr(gcs.get_mapper(URL), chunks={})
    block = era5.temperature.encoding["chunks"][0]  # time steps per stored block
    i0, i1 = np.searchsorted(era5.time.values, np.datetime64("1980-01-01")), np.searchsorted(era5.time.values, np.datetime64("2020-01-01"))
    steps = [i for i in range(i0, i1) if (i // block) % 4 == 0]
    subset = (
        era5[["temperature", "specific_humidity", "sea_ice_cover"]]
        .isel(time=steps)
        .sel(latitude=slice(60, 90))
        .load()
    )
    CACHE.parent.mkdir(exist_ok=True)
    subset.to_netcdf(CACHE)

subset = subset.sel(latitude=slice(60, 88))  # drop the pole row

Binning#

Every grid cell and time step is assigned to a bin of season, five-year period (1980–1984, …, 2015–2019) and sea-ice cover (0–0.1, …, 0.9–1; the first bin includes open water, land cells have no sea-ice cover and drop out). The mean profile of each bin is a plain average over grid cells, not area-weighted. n counts the samples per bin.

seasons = ["DJF", "MAM", "JJA", "SON"]
period_start = np.arange(1980, 2020, 5)

season_i = xr.DataArray(pd.Index(seasons).get_indexer(subset.time.dt.season.values), dims="time")
period_i = (subset.time.dt.year - 1980) // 5
sic_i = np.clip(np.floor(subset.sea_ice_cover * 10), 0, 9)  # NaN over land
key = (season_i * 80 + period_i * 10 + sic_i).rename("bin")

all_bins = np.arange(len(seasons) * len(period_start) * 10)
means = subset[["temperature", "specific_humidity"]].groupby(key).mean().reindex(bin=all_bins)
counts = key.groupby(key).count().reindex(bin=all_bins, fill_value=0)

labels = pd.MultiIndex.from_product(
    [seasons, [pd.Timestamp(f"{y + 2}-07-02") for y in period_start], np.round(np.arange(0.05, 1, 0.1), 2)],
    names=["season", "valid_time", "sea_ice_cover"],
)
profiles = (
    xr.Dataset({"t": means.temperature, "q": means.specific_humidity, "n": counts})
    .assign_coords(bin=labels)
    .unstack("bin")
    .rename(level="pressure_level")
    .sel(season=seasons)
    .transpose("season", "valid_time", "sea_ice_cover", "pressure_level")
)
profiles["t"].attrs = {"units": "K", "long_name": "temperature"}
profiles["q"].attrs = {"units": "kg kg-1", "long_name": "specific humidity"}
profiles["n"].attrs = {"long_name": "number of grid-cell samples"}
profiles["pressure_level"].attrs["units"] = "hPa"
profiles["valid_time"].attrs["long_name"] = "middle of the five-year period"
profiles.attrs["source"] = f"ARCO-ERA5 {URL.rsplit('/', 1)[-1]}, every fourth 25-day block, 60-88 N"

profiles.to_netcdf(OUTPUT)
