Water clouds#

Add a water cloud from a profile file with params and compute the solar and thermal net irradiance profiles. Clouds describes the file format and the other ways to define a cloud.

import pyradtran  # Registers the .pyradtran xarray accessor
from pyradtran import Var
from pyradtran import load_config
import matplotlib.pyplot as plt
import numpy as np
import xarray as xr
from pathlib import Path
import pandas as pd
import logging

# Show warnings only (set to DEBUG to see every uvspec call)
logging.getLogger('pyradtran').setLevel(logging.WARNING)

Scene#

One config each for the solar and the thermal run, and a single-time-step dataset: Leipzig at noon on 4 April, output every 0.5 km from the surface to 9.5 km and a surface temperature of 290 K. The surface albedo is 0.15 in the solar run (vegetation) and 0.02 in the thermal run (emissivity 0.98, \(\varepsilon = 1 - \alpha\)). Solar output is in mW m⁻², thermal in W m⁻² (units).

# ── Solar config ─────────────────────────────────────────────────────────────
cfg_solar = load_config()
cfg_solar.simulation_defaults.rte_solver           = "disort"
cfg_solar.simulation_defaults.mol_abs_param        = "reptran per_nm"
cfg_solar.simulation_defaults.source               = "solar"
cfg_solar.simulation_defaults.wavelength_nm        = [400, 3200]
cfg_solar.simulation_defaults.integrate_wavelength = True
cfg_solar.simulation_defaults.output_columns       = ["edir", "edn", "eup", "enet"]
cfg_solar.simulation_defaults.albedo_value         = 0.15
cfg_solar.execution.max_workers                    = 8
cfg_solar.execution.cleanup_temp_files             = False
solar_config_path = Path("config/cloud_solar.yaml")
cfg_solar.to_yaml(solar_config_path)

# ── Thermal config ────────────────────────────────────────────────────────────
cfg_thermal = load_config()
cfg_thermal.simulation_defaults.rte_solver           = "disort"
cfg_thermal.simulation_defaults.mol_abs_param        = "reptran medium"
cfg_thermal.simulation_defaults.source               = "thermal"
cfg_thermal.simulation_defaults.wavelength_nm        = [4500, 42000]
cfg_thermal.simulation_defaults.integrate_wavelength = True
cfg_thermal.simulation_defaults.output_columns       = ["edn", "eup", "enet"]
cfg_thermal.simulation_defaults.albedo_value         = 0.02   # emissivity 0.98
cfg_thermal.execution.max_workers                    = 8
cfg_thermal.execution.cleanup_temp_files             = False
thermal_config_path = Path("config/cloud_thermal.yaml")
cfg_thermal.to_yaml(thermal_config_path)

print(f"Solar config:   {solar_config_path}")
print(f"Thermal config: {thermal_config_path}")

# ── Input dataset ─────────────────────────────────────────────────────────────
ds = xr.Dataset(
    coords={
        'time'      : [pd.Timestamp('2025-04-04T12:00:00')],
        'latitude'  : ('time', [51.34]),
        'longitude' : ('time', [12.37]),
        'altitude'  : ('altitude', np.arange(0, 10, 0.5)),   # output levels, km
    },
    data_vars={
        'surface_temperature': ('time', [290.0]),  # K

Define a water cloud#

A libRadtran water cloud file has three columns: altitude (km), liquid water content (LWC, g m⁻³) and effective droplet radius (\(r_\mathrm{eff}\), µm), top of the atmosphere first. The value on a row applies to the layer between that level and the row above; the top row only closes the cloud (Clouds):

#      z     LWC    R_eff
#     (km)  (g/m³)  (µm)
      4.0    0.0    12.0     <- cloud top, value unused
      3.5    0.4    12.0     <- layer 3.5-4.0 km
      3.0    0.3    11.0     <- layer 3.0-3.5 km
      2.5    0.2    10.0     <- layer 2.5-3.0 km
      2.0    0.1     8.0     <- layer 2.0-2.5 km, cloud base

This is a cloud between 2 and 4 km whose LWC and droplet size increase towards the top, as in an adiabatic cloud. Its liquid water path is LWP = 0.5 km × (0.1 + 0.2 + 0.3 + 0.4) g m⁻³ = 500 g m⁻², which gives a visible optical thickness of roughly \(\tau \approx 3\,\mathrm{LWP}/(2\rho_w r_\mathrm{eff}) \approx 70\): an optically thick cloud. The next cell writes it to work/water_cloud.wc.

wc_content = """\
#      z     LWC    R_eff
#     (km)  (g/m^3) (um)
      4.0    0.0    12.0
      3.5    0.4    12.0
      3.0    0.3    11.0
      2.5    0.2    10.0
      2.0    0.1     8.0
"""

wc_file_path = Path('work/water_cloud.wc')
wc_file_path.parent.mkdir(parents=True, exist_ok=True)
wc_file_path.write_text(wc_content)

print(f"Water cloud definition written to {wc_file_path}")

Water cloud definition written to work/water_cloud.wc

Run solar and thermal simulations with params#

params sets or overrides any libRadtran input option at run time. The key wc_file 1D adds the line wc_file 1D work/water_cloud.wc to the input file, so libRadtran reads the one-dimensional water cloud profile written above.

Any option from the libRadtran documentation can be set this way (Parameters & Validation).

ds_sim_solar = ds.pyradtran.run(
    config_path=solar_config_path,
    return_dataset=True,
    save_to_file=True,
    params={
        'wc_file 1D' : 'work/water_cloud.wc',
    },
    show_progress=False,
)

ds_sim_thermal = ds.pyradtran.run(
    config_path=thermal_config_path,
    return_dataset=True,
    save_to_file=True,
    params={
        'sur_temperature': Var('surface_temperature'),
        'wc_file 1D' : 'work/water_cloud.wc',
    },
    show_progress=False,
)

Irradiance profiles#

Net solar, thermal and total irradiance against altitude. The grey band marks the cloud layer (2–4 km).

net_thermal = ds_sim_thermal.enet.squeeze()          # W m-2
net_solar = ds_sim_solar.enet.squeeze() / 1e3        # mW m-2 -> W m-2
net = net_solar + net_thermal

fig, ax = plt.subplots(figsize=(5, 8))
ax.axhspan(2.0, 4.0, color='gray', alpha=0.2, label='Water cloud (2–4 km)')
net_thermal.plot(y='altitude', ax=ax, marker='o', color='blue', label='Net thermal', lw=1, markersize=5)
net_solar.plot(y='altitude', ax=ax, marker='x', color='red', label='Net solar', lw=1, markersize=5)
net.plot(y='altitude', ax=ax, marker='s', color='black', label='Net total', lw=1, markersize=5)
ax.axvline(0, color='k', lw=0.5)
ax.set_xlabel(r'Net irradiance, $E^\downarrow - E^\uparrow$ (W m$^{-2}$)')
ax.set_ylabel('Altitude (km)')
ax.set_title('Leipzig, 4 April 2025, 12 UTC')
ax.legend(loc='lower right', fontsize='small')
ax.spines[['top', 'right']].set_visible(False)
ax.grid(True, linestyle='--', alpha=0.5)
plt.show()

print(net.to_pandas().round(1).to_frame('net total (W m-2)').T)

The flux divergence across a layer, \(\Delta E_\mathrm{net}\) between its top and its base, is the energy the layer absorbs:

  • Net solar irradiance (red) falls from about 160 W m⁻² at cloud top to about 70 W m⁻² below the cloud. The cloud absorbs about 90 W m⁻², most of it in the uppermost 500 m, and reflects much of the rest to space.

  • Net thermal irradiance (blue) is about −145 W m⁻² at cloud top, close to zero inside the opaque cloud and about −45 W m⁻² below it. The top layer loses about 140 W m⁻² by emission to space; the base layer gains about 40 W m⁻² from the warmer surface.

  • Total net irradiance (black): even at noon the longwave loss wins at cloud top (about −70 W m⁻² for the top layer), while the cloud base gains about 40 W m⁻². Cooling at the top and warming at the base is characteristic of optically thick water clouds.

The same cloud from CloudLayer#

CloudLayer describes a cloud by its boundaries and water content, and CloudFileWriter writes such layers to a cloud file at the exact layer boundaries. The four 500 m layers below reproduce the hand-written file. Clouds can also come from Python arrays, dataset variables or ERA5: see Clouds.

from pyradtran.clouds import CloudFileWriter, CloudLayer

layers = [
    CloudLayer(z_bottom_km=2.0, z_top_km=2.5, lwc_g_m3=0.1, r_eff_um=8.0),
    CloudLayer(z_bottom_km=2.5, z_top_km=3.0, lwc_g_m3=0.2, r_eff_um=10.0),
    CloudLayer(z_bottom_km=3.0, z_top_km=3.5, lwc_g_m3=0.3, r_eff_um=11.0),
    CloudLayer(z_bottom_km=3.5, z_top_km=4.0, lwc_g_m3=0.4, r_eff_um=12.0),
]
written = CloudFileWriter.write_water_cloud_file(layers, 'work/water_cloud_layers.wc')
print(written.read_text())

same = np.allclose(np.loadtxt(written), np.loadtxt(wc_file_path))
print(f"identical to work/water_cloud.wc: {same}")
