Debugging#

Check your input file!#

Most problems show in the input file that uvspec received.

Before running, explain() renders the annotated input file for one point:

print(ds.pyradtran.explain(params={...}, config_path=cfg))
# rte_solver disort          # config
# albedo 0.85                # dataset-var
# ...

After running, keep the generated .inp files:

execution:
  cleanup_temp_files: false

The working directory (default pyradtran_work/) then holds one .inp and one raw .out per point. Failed points keep their input file and the cloud files it references even with cleanup enabled, and their stderr goes to failures_<timestamp>.log.

What to check#

Line

What to look for

atmosphere_file, source solar

Do the paths exist? Right atmosphere model?

wavelength

Range in nm, supported by your mol_abs_param?

sza

> 90° means the sun is below the horizon: disort returns zeros, twostr fails (status == 1)

zout

Output altitudes in km, above the site’s altitude?

wc_file / ic_file

Cloud file exists? Columns are z(km), LWC/IWC(g/m³), r_eff(µm)?

Typos in option names and invalid values are caught before any run by the schema validation (Parameters & Validation). What still fails is usually a path or a physics mismatch.

Verbose logging#

import logging
logging.getLogger('pyradtran').setLevel(logging.DEBUG)

or execution.debug_mode: true in the config. Both log generated files, executed commands and raw uvspec output.

Common errors#

Messages from the failure log (failures_<timestamp>.log) or raised by pyRadtran before anything runs:

Message

Cause

Fix

ValidationError: 'albdeo' is not a known uvspec option … did you mean albedo

typo in a params key

fix the key; pyradtran.search_options() finds the right name

ValidationError: … value 1.5 outside [0.0, 1.0]

value outside the range libRadtran accepts

check pyradtran.describe(option)

ValidationError: … is not a configuration field; did you mean …

typo in a dotted config key

fix the key (Configuration lists all fields)

ValidationError: … matches a dataset variable name; use Var(...)

a bare string that is also a variable name

wrap it: Var("name")

required start wavelength: … is not in extraterrestrial solar flux file

wavelength_nm reaches beyond the solar spectrum file

narrow the range or pick another solar_spectrum (pyradtran.list_solar_spectra())

twostr_check_inputs--input and/or dimension errors

usually sza > 90° with twostr (night-time points)

use rte_solver: disort, or drop night points

NaN in broadband results with clouds

twostr instability in optically thick layers

rte_solver: disort

all values NaN, status == 0

output columns and parser disagree, typically with a hand-written output_user

set output_columns in the config instead and let pyRadtran add lambda/zout

PyRadtranError: All simulations failed

every point failed, usually for one common reason

read the first entry of the failure log, run that .inp by hand

ConfigurationError: LibRadtran executable / data directory not found

master config points to the wrong place

re-run pyradtran.save_master_config(...) (Installation)

run is very slow

fine spectral resolution over a wide range, or too many sweep points

coarser mol_abs_param (reptran coarse), integrate_wavelength, raise max_workers

Run a failing input by hand#

A kept .inp file is a complete uvspec input:

cd pyradtran_work
/opt/libradtran/bin/uvspec < tmpab12cd34.inp

Remove the quiet line (or add verbose) and uvspec reports which profiles it read, how it interpolated them and the optical depths.

Sanity checks#

  • Energy conservation: at the surface eup / (edir + edn) must reproduce the albedo you set. Check this with rte_solver: disort; the twostr surface eup does not satisfy it (Configuration).

  • Top of atmosphere: the downward irradiance at 100 km should be \(\mu_0 E_0\): about 1361 W m⁻² × \(\cos\theta_0\) for a full solar spectrum, scaled by the Sun–Earth distance.

  • Thermal, opaque limit: in a strong absorption band the brightness temperature must approach the air temperature at the sensor.

  • Units: broadband solar results in mW m⁻², thermal in W m⁻² (Units).
