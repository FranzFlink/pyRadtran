Configuration#

The configuration is merged from three YAML layers; later layers override earlier ones:

  1. Package defaults, shipped with pyRadtran

  2. Master config ~/.pyradtran/config.yaml: machine-specific paths, set once (see Installation)

  3. Simulation config, the YAML passed as config_path=: only what differs for this experiment

A typical simulation config is short:

simulation_defaults:
  source: solar
  rte_solver: disort
  mol_abs_param: lowtran per_nm
  wavelength_nm: [400, 770]     # nm; {start: 400, end: 770} also accepted
  output_columns: [eglo, eup, edir]
  output_altitudes_km: [0.0]

execution:
  max_workers: 8              # parallel uvspec processes
  timeout_seconds: 60
  cleanup_temp_files: false   # keep .inp files for debugging

Paths (libradtran_bin, libradtran_data, atmosphere_profile, solar_spectrum) belong in the master config and are inherited by every simulation.

Building configs in Python#

import pyradtran

cfg = pyradtran.load_config()               # defaults + master config
cfg.simulation_defaults.albedo_value = 0.2
cfg.to_yaml('config/my_simulation.yaml')    # save for reuse

A dotted key in params overrides a config field for one run:

ds.pyradtran.run(
    config_path='config/my_simulation.yaml',
    params={'simulation_defaults.wavelength_nm': [400, 700]},
)

Config or params?#

  • Config: what defines the experiment (solver, spectral range, output columns and altitudes, parallelism, paths)

  • params: what varies at run time (per-point values, parameter sweeps, extra uvspec options; see Parameters & Validation)

Both end up in the same input file; ds.pyradtran.explain() shows which layer produced each line.

Choosing solver and spectral resolution#

Goal

rte_solver

mol_abs_param

quick look, clear-sky irradiances

twostr

lowtran

broadband fluxes, clouds

disort

reptran coarse (or kato2 solar / fu thermal)

narrow-band instrument channels

disort

reptran medium / fine

radiances (uu), brightness temperatures

disort

reptran fine

Warning

twostr is a quick-look solver. With libRadtran 2.0.6 its upward irradiance at a reflecting surface is \(E^\uparrow = \tfrac{2}{\sqrt{3}}\,\alpha\,E_\mathrm{glo}\), about 15 % above the Lambertian value \(\alpha\,E_\mathrm{glo}\) that disort and rodents return. This is a property of uvspec, not of pyRadtran. Use disort (or rodents for a fast two-stream alternative) whenever eup, enet or the albedo matter.

pyradtran.describe("mol_abs_param") and pyradtran.describe("rte_solver") print the libRadtran documentation of the installed version.
